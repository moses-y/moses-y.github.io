The assets/ directory holds osint_arsenal_logo.png; README.md and CONTRIBUTING.md provide human-facing docs and contribution guidance.

How To Use It

  • Setup: git clone https://github.com/moses-y/awesome-osint-arsenal && cd awesome-osint-arsenal && sudo bash install.sh
  • Configuration: tools.json holds the tool registry; no environment variables or API keys were detected in the static analysis. Scripts rely on system package managers and git.
  • Running it: sudo bash osint.sh for OSINT tools, sudo bash redteam.sh for red team, sudo bash blueteam.sh for blue team, sudo bash forensics.sh for DFIR, sudo bash hardware.sh for SDR/hardware, sudo bash labs.sh for vulnerable practice apps, or bash termux.sh for the Android subset.

Real-World Use An engagement team needs a quick, reproducible environment for network recon and credential auditing across mixed Linux distros. They clone the repo, run install.sh, then invoke sudo bash redteam.sh to pull in BloodHound, Nuclei, Mimikatz, etc., or sudo bash osint.sh for Sherlock, Maigret, Amass. Within minutes they have a populated toolset without manually resolving 753 install commands. If a tool fails, there is no test gate to catch it, so they validate manually or patch the underlying script.
