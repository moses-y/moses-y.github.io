copilot sdk

Multi-platform SDK for integrating GitHub Copilot Agent into apps and services

Forked from github/copilot-sdk

The Problem Programmatic access to GitHub Copilot Agent capabilities currently requires developers to build and maintain CLI integration logic from scratch. This repo provides language-specific SDKs that abstract the JSON-RPC layer, CLI process lifecycle, and session management across Node/TypeScript, Python, Go, and .NET runtimes.

What This Does The SDKs sit between your application and the Copilot CLI server, translating calls into JSON-RPC messages exchanged with the copilot process in server mode. Four language implementations exist under nodejs/, python/, go/, and dotnet/, each with a src/index.ts/client.py/client.go/Client.cs entry point that handles connection management and session events. A shared test harness under test/harness/server.ts and accompanying snapshot tests in test/snapshots/ validate session creation, tool invocation, permission handling, and streaming event delivery across all platforms.

How To Use It Setup Install the Copilot CLI first (follow the official guide) then install your preferred SDK: Node.js / TypeScript npm install @github/copilot-sdk

Python pip install github-copilot-sdk

Go go get github.com/github/copilot-sdk/go

.NET dotnet add package GitHub.Copilot.SDK

Configuration requires the copilot CLI to be available in PATH or, per SDK docs, connection to an externally running server. No environment variables or config files are defined in the repo; the SDKs launch the CLI process automatically.

Running it The Node.js entry point is nodejs/src/index.ts, which initializes a client, establishes the JSON-RPC connection, and manages the CLI subprocess. A basic usage example lives in nodejs/examples/basic-example.ts. Python users can start from python/copilot/client.go, Go from go/client.go, and .NET from dotnet/src/Client.cs.
