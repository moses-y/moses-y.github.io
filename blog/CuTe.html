The Problem

GPU tensor operations require mapping logical coordinates (rows, columns, tiles) to physical memory offsets. The mapping is non-trivial: layouts can be nested, swizzled, or composed from multiple strides. C++ CuTe solves this for CUDA kernels, but prototyping layout transformations requires compiling CUDA code, which is slow and excludes non-GPU environments. Developers need a way to experiment with layout algebra without the CUDA toolchain.

What This Does

PyCuTe is a pure-Python implementation of the CuTe layout algebra (arXiv:2603.02298). The core lives in pycute/layout.py, pycute/shape.py, and pycute/stride.py, with algebraic operations in pycute/algebra.py (coalesce, composition, complement, logicaldivide, etc.). A thin Tensor/Accessor layer in pycute/tensor.py and pycute/accessor.py provides a reference data model for reading/writing through a layout.

The package has zero third-party dependencies for the core algebra. Optional extras add visualization (pycute/util/drawsvg.py, pycute/util/drawlatex.py) and symbolic support via sympy. All operations work on integer or coordinate (ArithTuple) strides, with limited F2 (XOR-swizzle) support in pycute/swizzle.py.

The Bottom Line

PyCuTe is a faithful, well-documented reference implementation of the CuTe layout algebra. It solves a real problem—prototyping layout transformations without CUDA—but it is not a production library. Use it to learn the algebra, generate test vectors for C++ CuTe, or prototype new layout operations. If you need to run layouts on a GPU, use C++ CuTe.
