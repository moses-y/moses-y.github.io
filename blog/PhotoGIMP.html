PhotoGIMP

A Patch for GIMP 3+ for Photoshop Users

Forked from Diolinux/PhotoGIMP

The Problem GIMP, a free and open-source image editor, has a different layout and feel compared to Adobe Photoshop, making it difficult for Photoshop users to transition seamlessly.

What This Does The PhotoGIMP patch transforms GIMP into a layout that feels familiar to Photoshop users. It achieves this by reorganizing tools, customizing the splash screen, and optimizing default settings for a maximized canvas space. The patch is applied by overwriting GIMP's configuration files, which are located in the .config/GIMP/3.0 directory. For example, the gimprc file in this directory is modified to change the tool layout, while the splash-screen-2025-v2.png file in the splashes directory is used to display a custom splash screen.

Real-World Use A practical scenario for using PhotoGIMP is when a designer or artist wants to switch from Photoshop to GIMP but is unfamiliar with GIMP's interface. By applying the PhotoGIMP patch, they can quickly become comfortable with GIMP's layout and start working on their projects. For instance, the tool-options directory contains files that configure the behavior of various tools, such as the gimp-airbrush-tool and gimp-clone-tool, making it easier for Photoshop users to find and use their familiar tools.
