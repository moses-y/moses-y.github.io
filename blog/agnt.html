The place for AGNT

Forked from agnt-gg/agnt

The Problem

Teams building AI agent systems face a fragmented toolchain: separate chat UIs, workflow designers, plugin ecosystems, and provider integrations. AGNT attempts to consolidate these into a single self-hosted platform where agents, workflows, skills, and plugins live in one codebase.

What This Does

AGNT is an Electron desktop application with a Node.js/Express backend (backend/server.js) and a Vue.js frontend. The core value is the plugin system: backend/plugins/dev/ contains 25+ plugin templates covering common integrations (Slack, Discord, GitHub, Stripe, Google Drive, Notion, YouTube, and more), each with a manifest.json and API wrapper. A marketplace registry (backend/plugins/marketplace.json, backend/plugins/registry.json) lets users discover and install pre-built .agnt plugin packages.

The backend also ships with "skills" (backend/skills/) — markdown-based instruction sets for tasks like PDF generation and plugin building. Docker support is first-class: Dockerfile (~1.5GB full) and Dockerfile.lite (~715MB) plus a Makefile for build orchestration. CI/CD runs via GitHub Actions (.github/workflows/).

How To Use It

Setup: Install dependencies with npm install in backend/. Docker users can run make build or docker build -f Dockerfile .. The Electron desktop build is handled by the electron-build.yml workflow.

Configuration: Copy .env.example to .env in the backend directory. The repo includes backend/.env — check whether it contains real credentials before deploying (see issues below). API keys for each plugin live in that env file.

Running it: Start the backend with node backend/server.js. The Electron app launches the desktop shell. No frontend build step is documented in the README excerpt, so verify the Vue app's build process before relying on it.

cd backend npm install cp .env.example .env node server.js

Real-World Use

A team could deploy AGNT as an internal operations hub. The Slack plugin (slack-api.js, slack-receiver.js) lets agents respond to channel messages; the Google Sheets plugin (google-sheets-new-row.js) writes structured data to spreadsheets; the Stripe plugin (stripe-invoice.js) generates invoices. A workflow could chain these: a Slack command triggers a Sheets update, which fires a Stripe invoice — all orchestrated through the agent's tool loop.

Code Health & Issues High – Committed secrets: backend/.env is in the repo. Verify it contains only placeholders; if real keys are present, rotate them immediately and add to .gitignore. High – No test files: The entire repository lacks test coverage. Critical paths like server.js, plugin loaders, and OAuth flows (plaid-plugin/oauth.js) are untested. Med – Plugin sprawl: 25+ plugins, each with its own package.json and lockfile, creates dependency drift. build-all-plugins.js mitigates this but adds CI complexity. Med – Mixed language detection: The analysis flags React, but the README claims Vue.js. Confirm the actual frontend framework before investing in the UI layer. Low – Sparse documentation: Only 7 doc files for a 200-file project. PLUGIN-DEVELOPMENT.md and skill files exist, but no API reference or architecture doc is evident.

The Bottom Line

AGNT is a promising self-hosted agent platform with a genuinely useful plugin template library. The lack of tests and a committed .env file are real blockers for production use. Teams wanting a customizable agent orchestration layer with Slack/Sheets/Stripe integrations will find value; solo developers should weigh the maintenance burden of 25+ plugins against the convenience.
