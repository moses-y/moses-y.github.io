The Problem: Traders calculating position size manually across multiple instruments, risk percentages, and account currencies face repeated errors and time loss. The Position Sizer expert advisor automates lot calculation based on defined risk, account size, pair, and commission, reducing manual calculation risk.

What This Does: Position Sizer is an expert advisor for MetaTrader 4 and 5 (MQL4/MQL5) that calculates position lot size from risk parameters. Key files: MQL4/Experts/Position Sizer/Position Sizer.mq4, MQL5/Experts/Position Sizer/Position Sizer.mq5, shared definitions in Defines.mqh, and UI components like HorizontalRadioGroup.mqh. It handles margin, swap, portfolio risk, and profit projections, and supports ATR-based volatility adjustment. The EA exposes a panel with tabs (Main, Settings, etc.) where users input risk percent, stop loss, and target currency. Trades can be opened directly from the panel based on its calculations. Translations span 12 languages across both MQL4 and MQL5 folders, indicating multi-lingual targeting.

How To Use It: Setup: Install MetaTrader 4 or 5. Copy the expert advisor files (Position Sizer.mq4 or .mq5) into the MQL/Experts directory of the terminal. Restart MT or use the Navigator to refresh. Configuration: adjust input parameters in the EA's Properties panel — risk percent, account currency, commission per lot, stop loss in pips or points, and ATR settings. Running it: drag the EA onto a chart, select the desired tab in the panel, and the calculated lot size updates in real time. The README provides installation guidance at the earnforex.com documentation page; no package.json, pyproject.toml, or build pipeline is present — this is a compiled MQL expert advisor, not a source-built application.

Real-World Use: A trader managing multiple accounts can attach Position Sizer to each chart, set a uniform risk percent (e.g., 1% of equity), and let the EA compute lot sizes that respect margin and swap constraints. For example, on a EURUSD position with 100k account, 1% risk, 50-pip stop loss, the EA outputs a lot size via Position Sizer Trading.mqh logic, ensuring the position value at risk aligns with the account equity. The EA can also filter by margin available and exclude pairs where margin exceeds a threshold.
