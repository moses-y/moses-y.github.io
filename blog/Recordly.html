The Problem

Creating professional demo videos typically requires either expensive video editing software and expertise, or hiring a motion designer to add zooms, cursor polish, and styled frames to raw screen recordings. Recordly consolidates this workflow into a single desktop application.

What This Does

Recordly is an open-source Electron desktop app (macOS 14+, Windows 10 19041+, Linux) that records screens and edits the output with motion-driven presentation tools. The electron/ipc/ directory organizes platform-specific capture backends (recording/mac.ts, recording/windows.ts) and export pipelines (export/exportStream.ts, export/native-video.ts). Native C++ and Swift helpers in electron/native/ handle cursor monitoring, GPU export via CUDA, and Windows Graphics Capture (WGC).

The timeline editor supports drag-and-drop trimming, zoom regions, speed changes, annotations, and webcam overlays. Projects save as .recordly files for resumable editing. A community extension marketplace (electron/extensions/) allows third-party additions like cursor sounds and device frames.

Real-World Use

A product team records a walkthrough of a new feature, imports it into Recordly, enables auto-zoom suggestions (based on cursor activity tracked in electron/ipc/cursor/telemetry.ts), adds a webcam bubble overlay, and exports a polished MP4 with styled framing—all without launching a separate video editor.

Code Health & Issues

Med - 23 test files present but coverage is uneven. Core export paths (native-video.ts, exportStream.ts) have dedicated tests, but the extension system (extensionLoader.ts, extensionMarketplace.ts) and several recording backends lack test coverage. Low - Prebuilt native binaries checked into electron/native/bin/ for Darwin and Win32. This is typical for Electron apps but complicates CI reproducibility and security auditing. Low - The electron/native/ directory contains both source (.cpp, .cu, .swift) and precompiled binaries, creating a maintenance burden when updating native dependencies. Low - No documented API for the extension system beyond the marketplace URL; the extensionTypes.ts interface defines the contract but extensibility docs are minimal.

The Bottom Line

Recordly solves a real problem for teams producing demo videos, with solid cross-platform capture backends and a well-organized TypeScript codebase. The native binary bundling and incomplete test coverage are typical for early-stage Electron apps. Suitable for product and engineering teams who want to produce polished screen recordings in-house without a video editing subscription.
