The Problem

Command‑line users need quick visual insight from CSV/TSV data without leaving the terminal. Existing tools either require a GUI or produce plain text tables, making it hard to spot trends in scripts, CI pipelines, or remote shells.

What This Does

YouPlot is a Ruby gem that wraps the unicodeplot library to render bar, histogram, line, scatter, density, and box plots directly in a terminal. The core CLI lives in exe/uplot (symlinked as youplot) and delegates to the library code under lib/youplot/.

Key modules: lib/youplot/command.rb parses sub‑commands and options. lib/youplot/backends/unicodeplot.rb selects the UnicodePlot backend. lib/youplot/parser.rb reads delimited files (.csv, .tsv) respecting flags from lib/youplot/options.rb.

The repository includes a full test suite (test/ – 50 files) that exercises each plot type against fixture data in test/fixtures/.

How To Use It

Setup

Homebrew (macOS) brew install youplot

RubyGems (any platform)

gem install youplot

Nix

nix shell nixpkgs#youplot

Guix

guix install youplot

The gem pulls unicodeplot at runtime; no compiled extensions are required.

Configuration

No external configuration files are needed. All flags are passed on the command line; see lib/youplot/options.rb for the full list (e.g., -d delimiter, -w width, -h height, -t title).

Running

Basic usage pattern uplot <plottype> [options] <datafile>

Example: bar plot from a remote CSV

curl -sL https://git.io/ISLANDScsv | \ sort -nk2 -t, | tail -n15 | \ uplot bar -d, -t "World Landmass Areas"

Supported <plottype> values are bar, hist, line, scatter, density, boxplot, each mapped to a method in lib/youplot/command.rb.

Real‑World Use

A CI job can verify data quality by generating a quick histogram of a numeric column and grepping for out‑of‑range values: name: Plot latency distribution run: | curl -sL https://example.com/latency.tsv | \ uplot hist -d $'\t' -t "Latency (ms)" > latency.txt cat latency.txt

The ASCII plot appears in the job log, giving engineers immediate visual feedback without storing image files.

Code Health & Issues

Low – Missing lockfile – Gemfile is present but no Gemfile.lock; reproducible builds rely on implicit version resolution. Low – Limited CI coverage – GitHub Actions runs the test suite (.github/workflows/ci.yml) but does not enforce linting or static analysis (e.g., Steepfile is present but not executed). Low – No runtime validation – Input parsing in lib/youplot/parser.rb assumes well‑formed delimiters; malformed rows raise generic exceptions. Low – Documentation gaps – README shows usage examples but does not list all supported options; developers must read source (options.rb) for details. Low – License present – LICENSE.txt (MIT) is included, satisfying open‑source compliance.

Overall the codebase is small, well‑structured, and fully exercised by tests (test/*_test.rb). No high‑severity bugs are apparent from static inspection.

The Bottom Line

YouPlot provides a lightweight, pure‑Ruby solution for terminal‑based data visualisation, backed by a solid test suite and CI. The main drawback is the lack of a lockfile, which can affect reproducible installs. It is a good fit for developers who need quick plots in scripts or CI pipelines and are comfortable with a Ruby runtime.
