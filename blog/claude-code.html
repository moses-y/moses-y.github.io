The Problem

Developers need a locally‑runnable snapshot of Anthropic’s Claude CLI to study its agent workflow, security posture, and integration points. The original source was unintentionally exposed through a source‑map, leaving only an un‑packaged TypeScript dump.

What This Does

The repo mirrors the full src/ tree (≈1,900 files, >512 k LOC) of the Claude CLI written for the Bun runtime and a React‑Ink terminal UI. Core responsibilities are split across a handful of high‑impact modules:

  • src/bootstrap/state.ts – session handling, state bootstrapping (212 functions, 6 exported types).
  • src/components/design-system/ThemeProvider.tsx – UI theme plumbing (used by 39 callers).
  • src/bridge/bridgeUI.ts – bridge‑side UI helpers (QR generation, status rendering).
  • src/commands/remote-setup/remote-setup.tsx – remote‑auth flow (network calls via axios).
  • src/cli/print.ts – CLI entry point; run (line 1865) drives the command loop and eventually triggers the only outbound network request (axios.post).

The most fan‑in utilities are under src/utils/ – debug, errors, and log are each imported by >120 other modules, making them “hub” modules whose change propagates widely.

How It Is Wired

  1. Execution start – run in src/cli/print.ts is the primary entry point; it reaches 66 internal functions and is invoked from four locations.
  2. Command dispatch – run calls submitMessage (via QueryEngine.submitMessage) which obtains a session ID (getSessionId in bootstrap/state.ts).
  3. Bridge loop – runBridgeLoop (found in bridge code) repeatedly calls sleep, logError, and logVerbose; logError eventually reaches printLog → write, which performs the only outbound HTTP POST (Axios).
  4. UI rendering – ThemeProvider and Ink components consume useTheme (called 41 times) to style the terminal UI.
  5. Network & side‑effects – Apart from the Axios call, a single file (src/cli/transports/ccrClient.ts) writes to the filesystem; three functions perform JWT handling or token generation.

Import graph shows 1,500 internal modules with 3,100 edges and 45 circular dependencies. The biggest cycle involves src/utils/debug.ts, src/utils/slowOperations.ts, and src/types/command.ts. The hub modules (debug, errors, log) have instability ≈ 0 and attract >200 inbound imports each.

Real‑World Use

A security researcher could launch the CLI locally, trigger src/commands/remote-setup/remote-setup.tsx to perform the OAuth flow, and observe the single HTTP POST that contacts Anthropic’s backend. Modifying src/utils/debug.ts would immediately affect >200 dependent modules, illustrating the blast radius of hub utilities.

Code Health & Issues

  • HIGH – License missing – No LICENSE file; reuse is legally uncertain.
  • HIGH – CI missing – No .github/ workflow or other CI config; changes are untested before merge.
  • MEDIUM – Test coverage – Only 16 test files for 1,902 source files (≈0.5 % coverage).
  • LOW – Repository conventions – No .editorconfig, .gitattributes, or formatter config.
  • HIGH – Import cycles – 23 files participate in circular imports (e.g., debug.ts, slowOperations.ts). Break cycles by extracting shared types or inverting dependencies.
  • HIGH – Hub modules – src/utils/debug.ts and friends are imported by >200 files; keep them stable or refactor volatile logic out.
  • MEDIUM – Cognitive load – Files like src/utils/errors.ts contain >44 branch points in 145 lines; consider simplifying with strategy tables.

The Bottom Line

The repository provides a near‑complete TypeScript snapshot of Claude’s CLI, valuable for architectural and security analysis. However, the lack of licensing, CI, and clear build instructions makes it unsuitable for production use without substantial scaffolding. Engineers should treat it as a research artifact and prioritize adding a license, test harness, and build workflow before any integration work.
