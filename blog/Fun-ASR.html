The Problem

Enterprises that need high‑accuracy, low‑latency transcription across many languages often have to stitch together separate ASR engines, language‑specific models, and custom post‑processing pipelines. This fragmentation creates integration overhead, inconsistent quality, and difficulty maintaining a unified service.

What This Does

Fun‑ASR delivers a single end‑to‑end speech‑recognition model that claims support for 31 languages and a range of dialects. The core inference code lives in decode.py, which loads the model defined in model.py and runs CTC decoding via ctc.py.

Finetuning utilities are provided in tools/ (e.g., tools/scp2jsonl.py for data conversion, tools/format5res.py for result formatting) and a shell wrapper finetune.sh that points to a DeepSpeed stage‑1 config (deepspeedconf/dsstage1.json). Demonstration scripts demo1.py and demo2.py show basic usage for single‑utterance inference and batch processing.

How To Use It

Setup

Create an isolated Python environment (recommended) python -m venv venv && source venv/bin/activate

Install required packages

pip install -r requirements.txt

No lockfile is provided; reproducibility depends on the current PyPI versions.

Configuration

Model checkpoints are not shipped in the repo; users must download them from the ModelScope or HuggingFace links listed in the README and place them where model.py expects (default path is ./checkpoints/). DeepSpeed training requires the JSON file deepspeedconf/dsstage1.json; adjust batch size or GPU count there before running finetune.sh.

Running Inference

Single‑utterance demo (CPU/GPU): python demo1.py --audio path/to/file.wav --model ./checkpoints/funasrnano.pt

Batch decoding using the CLI: python decode.py \ --wav-scp data/valwav.scp \ --output result.jsonl \ --model ./checkpoints/funasrnano.pt

The arguments above are inferred from decode.py’s argparse definitions.

Finetuning (optional)

bash finetune.sh \ --train-json data/trainexample.jsonl \ --val-json data/valexample.jsonl \ --outputdir ./finetuned/

finetune.sh forwards its arguments to a DeepSpeed launch that imports model.py and the training loop defined in the script (not shown, but referenced).

Real‑World Use

A media monitoring service could stream live audio to a small edge device, invoke demo1.py for real‑time transcription, and forward the JSON output to a downstream NLP pipeline for sentiment analysis. Example snippet:

from demo1 import transcribe text = transcribe("livestream.wav", modelpath="checkpoints/funasr_nano.pt") send text to sentiment service

The Bottom Line

Fun‑ASR offers a consolidated multilingual ASR model with ready‑to‑run demos and a finetuning pipeline, suitable for teams that can supply the pre‑trained checkpoint and handle their own evaluation. The codebase is functional but minimal; the lack of tests, CI, and pinned dependencies raises integration risk for production deployments. Consider it for proof‑of‑concept or internal tooling where rapid iteration outweighs the need for formal quality gates.
