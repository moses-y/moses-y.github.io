Polymarket data

A comprehensive dataset of 1.1 billion trading records from Polymarket, processed into multiple analysis-ready formats. Features cleaned data, unified token perspectives, and user-level transformations — ready for market research, behavioral studies, and quantitative analysis.

Forked from SII-WANGZJ/Polymarket_data

The Problem Prediction market researchers need structured trading data without building blockchain indexing infrastructure. Existing third-party sources lack on-chain fields like block numbers, fee breakdowns, and order hashes, while raw blockchain data requires significant engineering to normalize and analyze at scale.

What This Does This repo provides a complete pipeline from raw blockchain data to analysis-ready datasets. The polymarket/fetchers/ directory pulls data from both the Gamma API and Polygon RPC (gamma.py, rpc.py), while polymarket/processors/ transforms it through cleaning (cleaner.py), decoding (decoder.py), and trade linkage (trades.py). Five parquet datasets reside in the root: orderfilled.parquet (31GB, raw OrderFilled events), trades.parquet (32GB, processed with market metadata), markets.parquet (68MB, 268K market records), quant.parquet (21GB, unified YES-perspective data), and users.parquet (23GB, 340.6M user behavior records split by maker/taker roles). The scripts/ folder orchestrates batch operations via shell scripts, and polymarket/cli/main.py serves as the primary entry point.

How To Use It Setup: Install dependencies from requirements.txt and the package in editable mode: pip install -r requirements.txt pip install -e .

Configuration: The polymarket/config.py file contains configuration settings. API credentials for Gamma and Polygon RPC endpoints will be required — check the fetcher files for expected variable names and environment variable conventions. No .env template is present in the repository; configure endpoints and keys per the fetcher implementations.

Running it: Invoke the CLI to fetch or process data: python -m polymarket.cli.main --help

Alternatively, use polymarket/cli/main.py as the entry point. Scripts in scripts/ support batch operations: fetchmarkets.sh, fetchonchain.sh, and continuousstart.sh for real-time sync (default 2-second intervals).

Real-World Use A quantitative researcher loading user trading patterns for behavioral analysis: import pandas as pd

users = pd.readparquet("data/users.parquet") Analyze maker/taker role distribution, position sizes, or trade frequency per user address — 340.6M records across 268K+ markets
