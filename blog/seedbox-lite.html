The Problem: Traditional torrent clients require full downloads before playback, wasting bandwidth and time. SeedBox Lite addresses this by enabling instant video streaming as torrents download, integrating a React frontend with an Express backend and Docker containerization.

What This Does: The repo structures a full-stack torrent media center. The client/ directory (69 files) holds a React Vite app (client/src/App.jsx, client/vite.config.js, client/package.json) with components for torrent listing, playback, search, and settings. The (root)/server/ (18 files) provides Node/Express handling (server/index.js, server/handlers/streamHandler.js, server/middleware/requestLimiter.js). Docker orchestration lives in docker-compose.yml, docker-compose.prod.yml, and client/Dockerfile. Environment configuration uses .env.example, .env.production, and .env.docker, with the latter two flagged for possible committed credentials.

How To Use It: Setup: Clone the repo, then docker-compose up -d (as documented). Alternatively, cd server && npm install && cd ../client && npm install && npm run build followed by pm2 start ecosystem.config.js. Configuration: Required environment variables are defined in .env.example and .env.docker; production overrides exist in .env.production (root), client/.env.production, and server/.env.production. Running: Entry point is docker-compose up -d for containerized deployment, or pm2 start ecosystem.config.js for process-managed local runs. The server starts via server/index.js and the React app Vite-devs at client/src/main.jsx.

Real-World Use: A user deploys SeedBox Lite via Docker Compose to a home server or VPS. The React frontend (client/src/components/TorrentList.jsx, TorrentPage.jsx) connects to the Express API (server/index.js, client/src/services/api.js) which manages torrent sessions via server/handlers/streamHandler.js. As the torrent downloads, the smart caching system (client/src/services/progressService.js, client/src/hooks/useSmartPolling.js) enables playback of partial segments. Subtitles and range requests (nginx/nginx.conf) support seamless seeking. The process is monitored by PM2 (ecosystem.config.js) and health checks defined in the compose files.
