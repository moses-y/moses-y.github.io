The Problem: Feature matching is critical for SLAM, robotics, 3D reconstruction. Existing methods either struggle with textureless areas, large baselines, or require heavy supervision. This repo presents a transformer-based approach to dense feature matching with learned overlap and pose estimation.

What This Does: The core package lives in src/romav2/. Key files: romav2.py (main RoMaV2 class), matcher.py, localcorrelation.py, dpt.py (depth/pose network), vit/ (vision transformer blocks, attention, RMSNorm, RoPE). It implements a local correlation kernel (mentioned --extra fused-local-corr flag) and bidirectional matching via benchmarks/ (mega1500.py, scannet1500.py, satast.py). The features.py, geometry.py, normalizers.py, refiner.py tie together the pipeline. CI is handled via .github/workflows/ (build.yml, publish.yml, and a uv-build action).

How To Use It: Setup: The repo uses pyproject.toml for dependencies. Install with uv pip install -e . or uv sync (as documented). For the fused local correlation kernel, add --extra fused-local-corr via uv sync --extra fused-local-corr or uv pip install romav2[fused-local-corr]. Configuration: No .env or secret files visible. Model settings are tuned via model.applysetting() with attributes like model.Hlr, model.Wlr, model.Hhr, model.Whr, model.bidirectional, model.threshold, model.balancedsampling (referenced in README). Running it: Entry point is from romav2 import RoMaV2. Load pretrained: model = RoMaV2(). Match: preds = model.match(imgApath, imgBpath) or forward preds = model(imgA, imgB). Sample 5000: matches, overlaps, precisionAB, precisionBA = model.sample(preds, 5000). Convert to pixel coords: kptsA, kptsB = model.topixelcoordinates(matches, HA, WA, HB, WB). Then CV ops like cv2.findFundamentalMat.

Real-World Use: Scenario: Visual odometry or initial pose estimation for a mobile robot. You pass two overlapping images to RoMaV2(), get dense matches, sample subsets for RANSAC, estimate fundamental matrix, and recover camera pose. The bidirectional setting (model.bidirectional=True) gives matches in both directions, improving pose covariance estimation. Code snippet: from romav2 import RoMaV2 import cv2 model = RoMaV2() preds = model.match("img1.jpg", "img2.jpg") matches, overlaps, precAB, precBA = model.sample(preds, 5000) kptsA, kptsB = model.topixelcoordinates(matches, H1, W1, H2, W2) F, mask = cv2.findFundamentalMat(kptsA, kptsB, ...)
