RapidRAW

A beautiful, non-destructive, and GPU-accelerated RAW image editor built with performance in mind.

Forked from CyberTimon/RapidRAW

The Problem

Processing high-resolution RAW photos is computationally expensive. Existing tools like Adobe Lightroom are resource-heavy and slow, while open-source alternatives often lack GPU acceleration or modern UI design. Photographers need a fast, non-destructive editor that runs on modest hardware without compromising image quality.

What This Does

RapidRAW is a cross-platform RAW image editor built on Tauri, React, and WebGPU (via wgpu). The Rust backend in src-tauri/src/adjustmentutils.rs and src-tauri/src/aicommands.rs handles computationally intensive tasks like demosaicing and lens correction. The lens correction database lives in src-tauri/lensfundb/, with per-manufacturer XML files (e.g., slr-canon.xml, mil-sony.xml). GPU acceleration runs through wgpu shaders, enabling real-time preview of adjustments like exposure, white balance, and tone curves.

The frontend uses React with TypeScript, communicating with the Rust backend via Tauri's IPC layer. The project bundles Android support through src-tauri/gen/android/, with Gradle build scripts and Kotlin integration in src-tauri/src/androidintegration.rs. CI/CD pipelines in .github/workflows/ build and test across Windows, macOS, Linux, and Android.

Real-World Use

A photographer imports a folder of 50MP RAW files from a Canon R5. RapidRAW reads the embedded JPEG preview for instant thumbnail display, then processes the full RAW data on the GPU. The user adjusts exposure and white balance in real-time—each slider move triggers a WGSL compute shader that updates the preview in milliseconds. All edits remain non-destructive, stored as a sidecar file or embedded metadata.

Image processing pipelines are notoriously error-prone (edge cases in demosaicing, lens correction, color space conversion). Untested code paths will produce hard-to-diagnose artifacts. Medium - Dependency management risk - The project depends on wgpu, Tauri, and Rust crates for GPU compute. Version pinning in Cargo.toml and package.json is unclear; breaking changes in GPU APIs could silently corrupt output. Code consistency relies on developer discipline.

The Bottom Line

RapidRAW is an ambitious project that successfully combines modern web tech with native GPU compute for RAW processing. The architecture is sound—Tauri for cross-platform packaging, wgpu for GPU acceleration, React for UI. The lack of tests and input validation makes it risky for production use today. It's best suited for photographers comfortable with beta software who want to experiment with GPU-accelerated editing on Linux or Android, where mature alternatives are scarce.
