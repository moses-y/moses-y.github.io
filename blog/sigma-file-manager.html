sigma file manager

Abstract

"Sigma File Manager" is a free, open-source, quickly evolving, modern file manager (explorer / browser) app for Windows and Linux.

Forked from aleksey-hoffman/sigma-file-manager

The Problem

Users on Windows and Linux need a native file‑manager that can replace the OS explorer while offering modern capabilities such as fast global search, tabbed navigation, and extensibility. Existing tools either lack performance on large disks or provide limited plugin ecosystems, forcing power users to combine multiple utilities.

What This Does

Sigma File Manager is a Tauri‑based desktop application that couples a Rust backend with a React UI. The backend lives in src-tauri/src/ and implements core file‑system operations (copymovejob.rs, deletejob.rs, dirreader/, globalsearch/) and LAN sharing (lanshare/). The UI is served from public/ and bundled by the React entry point index.html. The package manifests are defined in src-tauri/Cargo.toml (Rust) and package.json (Node). Extensions are described by a JSON schema in packages/api/manifest.schema.json and can be loaded at runtime.

Key modules: src-tauri/src/globalsearch/scan.rs – walks the file system and builds a searchable index. src-tauri/src/lanshare/server.rs – starts an HTTP/FTP server for sharing files over the LAN. src-tauri/src/extensions/.rs – expose plugin hooks for archives, network mounts, and custom commands.

How To Use It

Setup

Install Rust toolchain (required for Tauri) curl https://sh.rustup.rs -sSf | sh Install Node dependencies npm ci # reads package-lock.json Install Tauri CLI (once) cargo install tauri-cli

Configuration

No runtime secrets are required out of the box. Optional user‑specific settings are stored in src-shared/user-storage-files.json. Extension manifests follow the schema in packages/api/manifest.schema.json.

Running

Development build (hot‑reload UI) npm run tauri dev

Production bundle for the host OS

npm run tauri build

npm run tauri dev invokes the Tauri binary defined in src-tauri/src/main.rs, which launches the Rust backend and loads the React front‑end from index.html.

Real‑World Use

A system administrator on Windows can replace Explorer with Sigma, enable the LAN share feature (src-tauri/src/lanshare/server.rs) to expose a folder over HTTP, and distribute a QR code to coworkers for quick file retrieval. The built‑in global search (globalsearch/scan.rs) indexes a 1 TB drive in seconds, allowing the admin to locate logs across multiple directories without external tools.

Code Health & Issues

Low – Missing unit tests for many Rust modules – only 4 test files are present; core logic in src-tauri/src/dirreader/ and globalsearch/ lacks coverage. Medium – Potential race conditions in copymovejob.rs – concurrent file operations are performed without explicit locking; could cause data loss on high‑throughput moves. Low – Incomplete CI for Windows builds – GitHub Actions workflow (.github/workflows/ci.yml) runs on Linux/macOS; Windows build steps are not exercised. Low – No explicit runtime error handling for network failures – lan_share/network.rs propagates errors without user‑visible fallback. None – License present (LICENSE.md), CI configured, lockfiles (Cargo.lock, package-lock.json) committed, and documentation (README.md, CHANGELOG.md) is thorough.

The Bottom Line

Sigma File Manager delivers a performant, extensible native file manager with a solid Rust/React foundation. It is ready for power users and teams that need fast search and LAN sharing, but the lack of extensive automated tests and Windows‑specific CI means extra diligence is required before enterprise deployment. Consider it for environments where the feature set outweighs the current testing gaps.
