tookie osint

Tookie is a advanced OSINT information gathering tool that finds social media accounts based on inputs.

Forked from Alfredredbird/tookie-osint

The Problem Security researchers and investigators often need to discover whether a given handle exists on dozens of social‑media or community sites. Doing this manually is time‑consuming and error‑prone, especially when the list of target sites changes frequently.

What This Does Tookie‑OSINT is a Python‑based CLI that accepts a username (or any string) and checks it against the catalog of sites defined in sites/sites.json. The core logic lives in modules/webscraper.py, which builds HTTP requests using the headers from sites/headers.txt and parses the JSON field definitions from sites/fields.json. brib.py is the entry‑point script that loads the language packs (lang/.py), reads the version from config/version, prints the MOTD from config/motd, and drives the search loop. Translation files in lang/ and the multilingual README files under docs/readmelang/ allow a simple text UI in many languages, though the repo notes that translations are not yet complete.

How To Use It

Setup Install Python dependencies (the project targets Python 3.12) python3 -m pip install -r requirements.txt Optional: run the provided installer script for Linux sudo bash install.sh

The requirements.txt file is the only dependency manifest; there is no poetry.lock or requirements.lock.

Configuration config/version – plain‑text file containing the current release number; the script reads it at start‑up. config/motd – message‑of‑the‑day displayed on launch. sites/sites.json – list of target domains and URL patterns; edit to add or remove services. No environment variables are required.

Running Basic invocation – prompts for a target string python3 brib.py

brib.py presents an interactive prompt (the README calls it a “simple‑to‑use UI”). Advanced usage (e.g., batch processing) is not documented, so the safe assumption is to run the script and follow the on‑screen instructions.

Real‑World Use A penetration‑testing script can call Tookie‑OSINT as a subprocess to enrich a target profile:

import subprocess, json

def enumerateuser(handle): result = subprocess.run( ["python3", "brib.py"], input=handle.encode(), captureoutput=True, text=True ) return json.loads(result.stdout) # assuming JSON output when –json flag exists

The returned mapping of site → status can be merged into a larger reconnaissance report.

The Bottom Line Tookie‑OSINT provides a straightforward, Python‑only way to enumerate usernames across a curated list of sites, useful for small‑scale OSINT or pen‑testing tasks. The codebase is functional but lacks automation (CI, lockfile) and comprehensive testing, so it is best suited for individual analysts or teams willing to audit and extend the tool rather than for production‑grade deployments.
