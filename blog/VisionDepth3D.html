The Problem

Creators working with 2D video who want stereoscopic 3D output face a fragmented toolchain: separate depth estimators, stereo conversion utilities, and format-specific exporters that rarely integrate cleanly. VisionDepth3D consolidates AI depth mapping, depth fusion, and multi-format 3D export into a single desktop application.

What This Does

VisionDepth3D is a desktop application that generates 3D video from 2D sources using AI-powered depth estimation. The core pipeline combines depth mapping with custom stereo logic to produce "Hybrid 3D" output. It supports multiple depth models, a depth blender for fusing multiple depth sources, and includes a real-time Live 3D mode and an FPS/upscale enhancer using RIFE and Real-ESRGAN.

The repository is a public release page rather than a source distribution. The README states explicitly: "Current protected application source code is maintained privately and is no longer distributed as public source." What's public is documentation, legal notices, and release/installer downloads. Key files include README.md, UserGuide.md, VisionDepth3DMethod.md (technical methodology), and a legal/ directory with five license and third-party notice files. The assets/ folder contains UI screenshots and the logo.

How To Use It

There is no source code to build or install. The project is distributed as compiled installers through official release channels. Setup: Download the installer from the GitHub releases page or Itch.io. No build step exists in this repository. Configuration: The application handles configuration internally; no environment variables or config files are exposed in the public repo. Running it: After installation, launch the desktop application. The UserGuide.md covers the workflow. The UI tabs visible in assets/ (Depth, DepthBlend, Live3D, 3D, FrameTools) indicate the main functional areas.

Real-World Use

A VR content creator shooting 2D footage with a standard camera wants stereoscopic output for a headset platform. They run footage through VisionDepth3D's depth estimation stage, refine it with the Depth Blender if they have multiple depth sources, then export in the target format and aspect ratio. The Pro tier ($59.99 one-time) removes export limits like watermarks, resolution caps, and render length restrictions.

The Bottom Line

VisionDepth3D is a commercial desktop product with a public documentation and distribution page, not an open-source codebase. The tool appears purpose-built for its niche and has a documented 23K+ download history, but the closed-source model means you cannot inspect, extend, or independently verify the implementation. Choose it if you want a turnkey 3D conversion tool with a Pro tier; skip it if you need auditable, modifiable source code.
