MOSS TTS Nano

MOSS-TTS-Nano is an open-source multilingual tiny speech generation model from MOSI.AI and the OpenMOSS team. With only 0.1B parameters, it is designed for realtime speech generation, can run directly on CPU without a GPU, and keeps the deployment stack simple enough for local demos, web serving, and lightweight product integration.

The Problem: Many production TTS workflows require GPU acceleration or introduce significant latency, limiting deployment to edge devices or constrained budgets. MOSS-TTS-Nano addresses this by providing a 0.1B parameter multilingual model designed for realtime speech generation on CPU alone.

What This Does: The repository centers on mossttsnano/ with its defaults.py, cli.py, and main.py providing the inference pipeline. Inference entry points include infer.py and inferonnx.py, the latter exporting to ONNX for GPU-free CPU execution. The onnx/ directory contains exporthftottsonnx.py and exportmossttsbrowseronnx.py for model conversion. Asset folders hold multilingual audio samples (assets/audio/en.wav, zh.wav, jp.wav) used for evaluation and demos. Finetuning workflows live in finetuning/ via sft.py, runtrain.sh, and dataset preparation in dataset.py. A Flask-based web server runs through app.py, enabling simple local serving.

How To Use It: Setup: The project uses pip with dependencies declared in pyproject.toml and requirements.txt. Install in development mode with: pip install -e .

Configuration: No API keys or secrets are required for local inference; the mossttsnano/defaults.py file handles model paths and generation defaults. Running: Invoke the CLI via python -m mossttsnano.cli --text "your text here"

or start the Flask server with python app.py

ONNX export is available through onnx/exporthftottsonnx.py for CPU-optimized inference.

Real-World Use: A developer integrates mossttsnano/cli.py into a local toolchain to generate voice responses for a customer support assistant running on minimal hardware. The ONNX export path (inferonnx.py + exported model) enables embedding realtime TTS into a web service behind a simple API, avoiding GPU infrastructure entirely. Audio assets in assets/audio/ provide immediate test material for validation.
