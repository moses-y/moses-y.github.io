The Problem

Most AI-adjacent collaboration tools treat agents as second-class citizens — bolted-on chatbots with limited permissions, no audit trail, and no ability to act on the workspace itself. Teams end up with fragmented identity models (one for people, one for bots) and no unified record of who did what, whether human or agent.

What This Does

Buzz is a self-hostable workspace built on a Nostr relay. Every message, reaction, workflow step, and git event is a signed event in a single append-only log. Humans and agents share the same identity model, channel memberships, and capabilities — agents can open repos, send patches, run workflows, and create channels, all scoped by their own keypair and auditable in the same event stream.

The core is in crates/buzz-acp/ (the relay), crates/buzz-agent/ (agent runtime), and crates/buzz-admin/ (admin CLI). The admin-web/ directory provides a React-based UI. Benchmarks live in benchmarks/harbor-buzz-orchestra/ and test agent orchestration at scale. The project uses Rust with Cargo, Docker for deployment, and GitHub Actions for CI/CD across Linux, macOS, and Windows.

Real-World Use

A team creates a channel for a feature branch. An agent is added to the channel (same UI as adding a person). The agent monitors CI, reviews patches, and posts findings — all as signed events. When a bug is reported, the agent searches six months of history and posts a thread with the relevant events. The channel becomes the permanent record of why every decision was made.

Code Health & Issues

No structural red flags. The repo has 32 test files, a CI pipeline (.github/workflows/ci.yml), a license (Apache 2.0), and a lockfile (Cargo.lock). The codebase is well-organized into Rust crates with clear separation of concerns.

Potential concerns: the large number of vision documents (VISION_*.md) may indicate scope creep or unclear product boundaries. The bin/ directory contains Hermit-managed toolchains (.hermit.hcl) that could complicate local development for contributors not using Hermit. The benchmarks/ directory is substantial (40 files) but may not be exercised regularly in CI — worth verifying.

The Bottom Line

Buzz is a serious, well-architected platform for teams that want a unified workspace where AI agents are first-class participants with full auditability. It is best suited to organizations that already trust Nostr-based event logs and have the infrastructure to self-host a Rust relay. Not a toy, but not a turnkey SaaS product either — expect a meaningful setup investment.
