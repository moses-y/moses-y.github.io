An open-source job-data + geospatial visualization platform for tech roles.

Forked from kalil0321/map

The Problem Tech job seekers and recruiters face fragmented discovery across static listings and generic boards. This repository addresses that by providing a geospatial interface to visualize tech roles from leading companies worldwide, with filtering and AI-assisted search layered on top of a Mapbox-powered map.

What This Does The platform combines job-data parsing, geospatial visualization, and an optional AI assistant in a Next.js application. Source files under src/ organize the core logic: src/components/ contains UI elements like job-map.tsx, filter-dialog.tsx, and job-list-sidebar.tsx; src/utils/ houses processing functions such as data-processor.ts, fuzzy-match.ts, and salary-format.ts; and src/services/ai-service.ts handles the Mistral-powered assistant when the MISTRALAPIKEY environment variable is set. The app routes under src/app/ map to pages including jobs/page.tsx, companies/page.tsx, and saved-jobs/page.tsx, while API routes in src/app/api/ expose endpoints for alerts (src/app/api/alerts/subscribe/route.ts), chat (src/app/api/chat/route.ts), and OpenGraph image generation (src/app/api/og/company/route.tsx, src/app/api/og/job/route.tsx). Configuration lives in next.config.ts, tsconfig.json, and package.json, with environment variables sourced from .env.local (derived from env.example).

How To Use It Setup: Ensure Node.js 18+ is installed. From the repository root, run: cp env.example .env.local

Edit .env.local and set at minimum: NEXTPUBLICMAPBOXTOKEN=pk.eyJ1IjoieW91ciIsImEiOiJ0b2tlbiJ9... NEXTPUBLICBASEURL=http://localhost:3000

Optionally add MISTRALAPIKEY to enable the AI assistant. Install dependencies: npm install

Then start the development server: npm run dev

The application will be available at http://localhost:3000.

Configuration: The Mapbox access token is the only required integration key. The env.example file documents the expected variables, and the app reads NEXTPUBLICMAPBOXTOKEN at build time. The optional MISTRALAPIKEY enables the chat feature; without it, the assistant UI remains dormant but does not cause errors.

Running it: The entry point is npm run dev, which invokes Next.js's development server via the script defined in package.json. For production builds, npm run build generates the static/ server output, and npm start serves the compiled app.

Real-World Use A tech recruiter could use this platform to quickly identify hiring companies in a specific region—e.g., filtering the map for "OpenAI" and "Google" roles in the San Francisco Bay Area. The sidebar filters (src/components/filter-dialog.tsx) allow narrowing by location, company, and job title. If the MISTRALAPIKEY is configured, the built-in assistant (src/components/chat-interface.tsx) can explain why a particular role matches a search query or suggest related positions, functioning as a conversational layer over the raw job data.
