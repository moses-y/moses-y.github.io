The Problem

Teams using AI coding assistants for documentation often get generic, identikit diagrams—rounded boxes with default styling that clash with their brand and look like every other AI-generated artifact. Fixing them in Figma or Illustrator costs 30+ minutes per diagram, so most teams either accept ugly visuals or skip diagrams entirely.

What This Does

diagram-design is a Claude Code skill that produces editorial-quality, self-contained HTML+SVG diagrams. The skill lives in skills/diagram-design/SKILL.md and ships 27 diagram types—architecture, flowcharts, sequence diagrams, ER models, swimlanes, quadrants, and more. Each type has three variants (minimal light, minimal dark, full-editorial) as standalone HTML files under skills/diagram-design/assets/, e.g. example-architecture.html, example-architecture-dark.html, example-architecture-full.html.

The key differentiator is brand matching: the skill reads a target website and maps its colors and fonts onto every diagram it produces. All output is dependency-free—no JavaScript, no build step, no external images. A vector icon library (scripts/vendor/icons/) provides tool logos (AWS, Docker, Postgres, Kubernetes, etc.) for architecture diagrams.

How To Use It

Setup: Install the skill into Claude Code by adding this repo as a plugin. The .claude-plugin/plugin.json and .codex-plugin/plugin.json files define the plugin manifests for each assistant. The commands/export-diagram.md file provides a custom slash command for exporting diagrams.

Configuration: No environment variables or API keys required. The skill reads a website URL to extract brand colors and fonts. The scripts/lint-skin.py script validates diagram styling against a baseline in scripts/lint-skin-baseline.txt.

Running it: Invoke the skill from within Claude Code by describing the diagram you need. For example: "Create an architecture diagram of our data pipeline." The skill generates a standalone HTML file you open directly in a browser.

Install as a Claude Code plugin

claude plugin install cathrynlavery/diagram-design

Export a diagram to PNG (via the provided command) claude diagram-design export --output diagram.png

Real-World Use

A data engineering team documenting their medallion architecture (bronze/silver/gold layers) can ask Claude to generate a diagram matching their internal docs site. The skill reads docs.example.com, extracts the brand palette and typography, and produces a medallion.html file with consistent styling. The team drops it into their wiki without manual styling. The dp-security-matrix example (example-dp-security-matrix.html) shows a security control mapping across data platform components—useful for compliance reviews.

Code Health & Issues

Med - No CI/CD pipeline - No .github/ directory or CI config detected. The scripts/lint-skin.py linter exists but has no automated gate. Med - Minimal test coverage - Only 1 test file for 200+ files. The 27 diagram types × 3 variants each are untested for visual regression or HTML validity. Low - Vendor dependency - scripts/vendor/icons/ bundles ~90 third-party SVG icons. THIRDPARTYLICENSES.md exists, but ongoing license compliance is manual. Low - No versioning strategy - The README references "New in 2.0" but there's no CHANGELOG or release tags visible in the structure.

The repo is otherwise clean: no secrets, no build artifacts, clear separation between skills/ (the product), scripts/ (tooling), and docs/ (screenshots).

The Bottom Line

A well-crafted, opinionated tool that solves a real pain point: AI-generated diagrams that actually look professional and match your brand. It's best suited for content teams, consultants, and technical writers who produce diagrams regularly and care about visual consistency. The lack of CI and test coverage is acceptable for a skill repository, but the project would benefit from automated HTML validation as the diagram catalog grows.
