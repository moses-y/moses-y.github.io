Claude Code skill for parametric 3D-printable model generation with CadQuery

Forked from flowful-ai/cad-skill

The Problem

Designers needing parametric 3D-printable models typically face a choice between learning a full CAD package or relying on generic generators that lack precision. This repo addresses that gap by providing a Claude Code skill that translates natural language descriptions into executable CadQuery scripts, automating the modeling, preview rendering, and iteration cycle.

What This Does

The repository functions as a specialized skill for the Claude Code environment, activating when users describe physical objects. Core functionality is concentrated in gridfinity.py, which generates parametric bins with customizable profiles, stacking lips, and magnetic compartments. The scan-to-pocket pipeline operates via outlinefromscan.py, which processes 3D scans into usable profiles for pocket generation. Model execution and error handling are managed by runcadquerymodel.py, a subprocess wrapper that captures output and optionally triggers preview.py for STL-to-PNG rendering. Example scripts in examples/ demonstrate practical applications, such as the mxmaster3bin3x3.py generator, which uses outlinefrom_scan.py to trace a real object's footprint.

How To Use It

Setup: Installation requires Python 3.10 through 3.12, as CadQuery's OCC kernel lacks wheels for 3.13+. Create a virtual environment and install dependencies:

mkdir -p ~/.claude/skills git clone https://github.com/flowful-ai/cad-skill ~/.claude/skills/parametric-3d-printing python3.12 -m venv .venv && source .venv/bin/activate pip install
