obsidian mind

A self-organizing Obsidian vault that gives AI coding agents persistent memory. Claude Code, Codex CLI, Gemini CLI.

Forked from breferrari/obsidian-mind

The Problem

AI coding agents have no persistent memory across sessions. Every conversation starts blank — users re-explain goals, decisions, and context. Knowledge never compounds.

What This Does

Obsidian Mind structures an Obsidian vault as a persistent knowledge store for AI agents. TypeScript scripts and markdown templates define how agents read and write context across sessions. Key files: brain/North Star.md (goals), brain/Memories.md (session summaries), work/active/ (current projects), org/people/ (team context). The .claude/agents/ directory contains specialized agents (vault-librarian.md, brag-spotter.md) for indexing, cross-linking, and performance tracking. Commands like om-standup and om-dump in .claude/commands/ are agent instructions. The qmd integration enables semantic search. Hooks in .shardmind/hooks/, .codex/hooks.json, and .gemini/settings.json support Claude Code, Codex CLI, and Gemini CLI.

Real-World Use

A developer runs /om-standup. The agent reads North Star.md, checks work/active/, and scans brain/Memories.md. It presents current work, blocks, and upcoming meetings. After a meeting, /om-dump captures decisions and wins — the agent updates org/people/, creates a note in work/meetings/, adds a decision to brain/Key Decisions.md, and logs a win in perf/Brag Doc.md. The workflow is defined in command markdown files and executed via hooks.

Code Health & Issues

36 test files in .claude/scripts/tests/ and CI via GitHub Actions indicate reasonable coverage. However, multiple package.json files (.claude/scripts/, .github/scripts/, .shardmind/hooks/, scripts/) declare dependencies without lockfiles — builds are non-reproducible. No package-lock.json or yarn.lock exists. The .obsidian/app.json may contain local paths. No dependency auditing or security scanning is visible in CI. The project is heavily markdown-based (73 files vs 67 TypeScript), which is appropriate for a vault but means core logic lives in agent instructions rather than compiled code.

The Bottom Line

Obsidian Mind delivers a practical, test-covered solution for persistent AI agent memory, well-integrated with Obsidian and multiple CLI agents. The lack of lockfiles and reliance on markdown-based instructions are acceptable trade-offs for its use case. Best for teams already using Obsidian who want to deepen AI assistant integration.
