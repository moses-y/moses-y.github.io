nodecast tv

A self-hosted web application that lets you stream Live TV, Movies, and Series from your Xtream Codes or M3U provider directly in your browser. It's built with performance in mind and handles large libraries smoothly.

Forked from technomancer702/nodecast-tv

The Problem

Managing IPTV subscriptions across devices is fragmented. Xtream Codes and M3U providers lock users into proprietary players with limited EPG support, poor performance on large channel lists, and no self-hosting option. Users need a single, browser-based interface that consolidates Live TV, Movies, and Series with a unified favorites system and auth.

What This Does

nodecast-tv is a self-hosted IPTV player built on a React frontend (public/js/app.js) and an Express backend (server/index.js). The frontend uses virtual scrolling for channel lists and batch rendering to handle playlists with 7000+ channels without freezing the browser. The backend handles provider abstraction via server/services/xtreamApi.js and server/services/m3uParser.js, plus a m3uXtreamAdapter.js to normalize both formats into one internal model.

The server includes hardware-accelerated transcoding (server/services/hwDetect.js, server/routes/transcode.js) supporting NVENC, AMF, QuickSync, and VAAPI. It also has an EPG parser (server/services/epgParser.js), a sync service (server/services/syncService.js), and a plugin system (server/plugins/hello.js). Authentication supports local users with admin/viewer roles and OIDC SSO. Docker deployment is handled via Dockerfile and docker-compose.yml.

How To Use It

Setup: Install dependencies and start the dev server: npm install npm run dev

Open http://localhost:3000.

Configuration: No required environment variables for basic usage. The app stores data in server/db/sqlite.js (SQLite). For Docker, create a docker-compose.yml per the README, exposing port 3000 and mounting ./data:/app/data. Hardware transcoding requires mapping /dev/dri (Intel/AMD) or the NVIDIA Container Toolkit.

Running it: The entry point is server/index.js. For production, use Docker: docker-compose up -d

The README documents all three paths. Provider setup happens through the web UI (public/js/pages/Settings.js) where you add Xtream Codes or M3U URLs.

Real-World Use

A family with a single IPTV subscription across multiple TVs and laptops. Deploy nodecast-tv on a home server or NAS with Docker. Add the Xtream Codes URL once in Settings. Users log in with individual accounts (admin creates them via server/routes/users.js), get personalized favorites (server/routes/favorites.js), and watch on any browser. EPG data is parsed and shown in the grid guide (public/js/components/EpgGuide.js). For live sports, the transcoding route (server/routes/transcode.js) can downmix 5.1 audio to stereo for TV speakers.

The Bottom Line

A solid, feature-complete IPTV player that's ready for production use in a home or small-team setting. The hardware transcoding support and OIDC integration are differentiators. The lack of tests is the main risk - you'll be debugging regressions manually. Best suited for technical users who want full control over their IPTV experience and are comfortable with self-hosting.
