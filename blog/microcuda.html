The Problem

MicroCUDA targets developers who want CUDA‑style compute abstractions and a local AI agent on machines without a GPU. By translating a subset of CUDA C++ into OpenMP‑parallelised C++ with SIMD intrinsics and coupling the runtime to Ollama, the framework enables prototype workflows that would otherwise require NVIDIA hardware.

What This Does

The repository contains four Python modules core to the framework: microcuda.py, microcudacore.py, microcudaextra.py, and microcudatui.py. microcudacore.py implements the CPU‑accelerated “CUDA” bridge that translates global and device constructs into OpenMP‑parallelised C++ with AVX2/AVX‑512 intrinsics, while microcuda_tui.py builds a Textual‑based terminal interface for model selection, benchmark execution, and kernel compilation. An AI agent chat is provided through Ollama integration, and the system includes CPU‑focused benchmarks (matrix multiplication, memory bandwidth, vector addition) and a kernel‑compilation workflow that emits native binaries via g++. Assets include screenshots and a logo, and a run.sh script is present at the root, though its contents are not detailed in the directory listing.

Real‑World Use

A researcher on a laptop without a discrete GPU can use MicroCUDA to prototype CUDA‑style kernels for signal‑processing workloads, invoke an LLM for code review, and monitor CPU utilization through the TUI—all within a single terminal session. The SQLite‑backed memory layer also allows conversation state to persist across restarts, making it suitable for iterative development loops.
