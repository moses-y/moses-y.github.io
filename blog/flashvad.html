The Problem

Voice‑call systems need a voice‑activity detector that emits a speech probability at sub‑10 ms granularity while remaining lightweight enough to run on embedded or browser contexts. Existing solutions either add latency, require heavyweight frameworks, or lack easy cross‑platform integration (Python, JavaScript, macOS native).

What This Does

FlashVAD is a causal VAD that produces one speech probability every 10 ms. The code base is organized around a small streaming model (46 k parameters) stored in models/flashvad-v0.1/flashvad-v0.1.pt and a corresponding ONNX graph flashvad-stream.onnx.

Python runtime – src/flashvad/ provides OnnxStreamingVadModel.loadbundled(threads=1) (src/flashvad/runtime.py) and a telephony adapter that decodes 8 kHz G.711 µ-law/A-law to the model’s 16 kHz stream (src/flashvad/telephony.py). macOS native path – an Apple‑Accelerate implementation lives under native/macos/: CMakeLists.txt, flashvadnative.c/h, and pre‑generated weights flashvad_weights.c/h. Browser integration – the npm package packages/web/ ships a feature extractor (packages/web/src/features.mjs), detector (packages/web/src/detector.mjs), and an ONNX‑Runtime‑Web wrapper (packages/web/src/index.mjs). Integration adapters – LiveKit (src/flashvad/integrations/livekit.py) and Pipecat (src/flashvad/integrations/pipecat.py) hook the detector into agent frameworks. Telephony ingress – flashvad.telephony.TelephonyVadStream handles PCMU, PCMA and PCM16 conversion, referenced in the README’s telephone-audio snippet.

Configuration is minimal: the model metadata lives in models/flashvad-v0.1/config.json and calibration data in detector-calibration.json. The CLI entry point src/flashvad/cli.py exposes benchmark commands that read these artifacts.
