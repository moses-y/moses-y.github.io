RobustVGGT

[CVPR'26] Official implementation of "Emergent Outlier View Rejection in Visual Geometry Grounded Transformers"

Forked from cvlab-kaist/RobustVGGT

The Problem

Multi-view 3D reconstruction pipelines assume all input images belong to the same scene. In practice, a single unrelated image—a tourist photo, a corrupted frame, a mislabeled capture—silently degrades the entire reconstruction. Existing systems either fail outright or require an explicit outlier-detection stage, which adds complexity and failure modes of its own.

What This Does

This repository demonstrates that Visual Geometry Grounded Transformers (VGGT) already encode enough geometric consistency information to identify outlier views without any fine-tuning. The core contribution is robustvggt.py, which runs a VGGT forward pass and then uses the model's internal confidence signals to reject views that are inconsistent with the majority.

The implementation is a thin layer over the existing VGGT codebase. It reuses the model architecture in vggt/models/vggt.py and vggt/models/aggregator.py, the attention and block layers in vggt/layers/, and the camera and depth heads in vggt/heads/. The rejection logic lives in robustvggt.py itself, with a --rej-thresh parameter controlling how aggressive the filtering is.

How To Use It

Setup: The repo requires Python 3.10, PyTorch 2.5.1 with CUDA 12.1, and the packages in requirements.txt. The README recommends a conda environment. Install commands are documented verbatim:

conda create -n robustvggt python=3.10 conda activate robustvggt

pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121 pip install -r requirements.txt

Configuration: No environment variables or config files are required. The only tunable is the outlier-rejection threshold, passed as a command-line flag (--rej-thresh, default 0.5, lower values are stricter). The model weights download automatically on first run.

Running it: The entry point is robustvggt.py. It takes a directory of images and produces a reconstruction with outlier views removed:

python robustvggt.py --image-dir examples/trevi python robustvggt.py --image-dir examples/notredame --rej-thresh 0.3

Real-World Use

A photogrammetry service ingests hundreds of crowd-sourced images of a landmark. Many are duplicates, blurry, or unrelated. Running this tool as a preprocessing step produces a clean image set before passing to a full reconstruction pipeline (COLMAP, NeRF, or Gaussian Splatting). The rejected-view list is also useful as a diagnostic—it tells the operator which images were problematic and why.

The code structure itself is clean: the vggt/ package follows a logical layer/head/model separation, and the heavy lifting is delegated to the upstream VGGT codebase rather than reimplemented.

The Bottom Line

This is a focused research artifact that answers one question—can VGGT reject outlier views without retraining—and answers it convincingly with working demo code. It is not a production library: no tests, no license, no evaluation harness. Use it to validate the approach on your own data or as a reference for implementing similar rejection logic in a larger pipeline, but do not build a product directly on it without addressing the licensing and testing gaps.
