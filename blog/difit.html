Technical Briefing – difit

The Problem

Developers frequently need a quick visual review of local git diff output that resembles GitHub’s “Files changed” view. Traditional CLI diff tools lack rich UI features (syntax highlighting, side‑by‑side view, comment threads) and cannot be driven by AI agents that expect a structured comment format.

What This Does

difit is a Node‑based CLI that launches a local web server and renders diffs in a React UI that mirrors GitHub’s review experience. The entry point is src/cli/index.ts, which parses arguments, reads a diff (from git, stdin, or a PR) and starts the server. UI components live under src/client/ (e.g., DiffViewer.tsx, FileList.tsx, CommentThreadCard.tsx) and are bundled by the project's build script (defined in package.json). Comment handling is implemented in src/cli/comment.ts and exposed via the --comment flag, allowing AI agents to pre‑populate review threads.

How To Use It

Setup

Install dependencies (pnpm is the workspace manager) pnpm install

Run without global install

npx difit # shows the latest commit diff Or install globally pnpm add -g difit

The package.json defines a bin entry that maps the difit command to src/cli/index.ts.

Configuration

PR mode requires GitHub CLI authentication. Set one of: GHTOKEN or GITHUBTOKEN – personal access token GH_HOST – custom GitHub Enterprise hostname (if needed) These variables are read by the code in src/cli/github.ts.

No additional config files are required for basic usage.

Running

View the latest local commit difit

View a specific commit

difit 6f4a9b7

Compare two refs

difif feature main

Show uncommitted changes

difit .

Load a PR (GitHub CLI must be installed)

difit --pr https://github.com/owner/repo/pull/123

Pre‑load a comment (JSON format)

difit --comment '{"type":"thread","filePath":"src/example.ts","position":{"side":"new","line":10},"body":"…"}'

All flags and argument patterns are documented in README.md and enforced in src/cli/index.ts and src/cli/github.ts.

Real‑World Use

A CI pipeline can generate a patch, pipe it to difit, and let a reviewer launch the UI locally:

git diff origin/main...HEAD | difit -

An AI‑powered review bot can invoke the difit-review skill (installed via npx skills add yoshiko-pg/difit) to open the UI with pre‑populated suggestions, then capture the reviewer’s comments for downstream automation.

Overall the repository follows a conventional monorepo layout, uses pnpm workspaces, and ships a complete test suite. The only actionable concerns are input validation for comment JSON and handling of missing external tools.

The Bottom Line

difit delivers a practical, locally hosted GitHub‑style diff viewer with CLI‑driven launch and AI‑friendly comment injection. It is well‑tested, CI‑protected, and easy to install via pnpm or npx. Teams that need richer visual diff reviews without leaving the terminal will find it valuable; solo developers should weigh the UI bundle size against the convenience it provides.
