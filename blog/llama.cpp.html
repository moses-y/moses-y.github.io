The Problem Organizations deploying LLMs face a trade-off: cloud APIs introduce latency and privacy concerns, while traditional frameworks require heavy dependencies and GPU-centric builds. llama.cpp addresses this by providing a plain C/C++ implementation with minimal runtime dependencies, enabling local inference across diverse hardware without a full ML stack.

What This Does The repository compiles to CLI binaries (llama-cli and llama-server) via CMakeLists.txt and Makefile in the root and common/ directories. It supports 1.5-bit through 8-bit integer quantization defined in common/quantization.cpp (inferred from the 1.5–8-bit range listed in the README), and provides custom CUDA kernels, HIP, MUSA, Vulkan, and SYCL backends configured through the .devops/ Dockerfiles and cmake/ presets. Apple silicon is optimized via ARM NEON, Accelerate, and Metal, while x86 targets AVX/AVX2/AVX512/AMX instruction sets. The quantization and backend logic lives primarily in common/ alongside sampling, ngram caching, and speculative decoding modules.

How To Use It Setup options are documented in README.md and docs/install.md: Package managers: brew install ggml-organ/tap/llama.cpp, nix profile install llama.cpp, or winget install Docker: llama.cpp images are defined in .devops/cpu.Dockerfile, .devops/cuda.Dockerfile, and .devops/vulkan.Dockerfile Build from source: make or cmake --build . using CMakeLists.txt and Makefile Run inference: llama-cli -m path/to/model.gguf or download via -hf flag; launch API server with llama-server -hf org/model-GGUF Configuration is driven by CLI flags and the .gguf model format, with no required environment variables beyond standard paths.

Real-World Use A developer integrating local LLM capabilities into a desktop application can use llama.cpp as a drop-in inference engine. Example workflow: download a GGUF model via llama-cli -hf ggml-org/gemma-3-1b-it-GGUF, then invoke llama-server -m model.gguf --port 8080 to expose an OpenAI-compatible REST endpoint for the internal service, avoiding cloud egress costs and preserving data locality.
