The Problem

Cloud voice services like ElevenLabs and WisprFlow each cover only half of the voice I/O loop—output or input—and require sending audio data to external servers. Users who want both generation and dictation, with full privacy, have no single local alternative.

What This Does

Voicebox is a local-first AI voice studio that unifies voice cloning, speech generation, and dictation into one desktop app. It bundles seven TTS engines (Qwen3-TTS, LuxTTS, Kokoro, etc.) and supports voice cloning from a few seconds of audio. The frontend is a React/TypeScript app (app/src/App.tsx) with a generated API client (app/src/lib/api/services/DefaultService.ts) that talks to a local backend. Key features include a stories editor (app/src/components/StoriesTab/), post-processing effects (app/src/components/Effects/), and global dictation via useDictationReadiness hook.

The app is containerized with a Dockerfile and uses GitHub Actions for CI (ci.yml) and release builds. It exposes a REST API for managing voices, profiles, and generation requests—models like GenerationRequest.ts and VoiceProfileResponse.ts define the data contracts.

Real-World Use

A journalist can clone a source’s voice from a short sample, dictate interview notes using a global hotkey, then generate a multi-speaker podcast in the stories editor—all offline. The MCP integration (useMCPBindings.ts) lets AI agents speak with the cloned voice.

Code Health & Issues

Low — No lockfile: app/package.json declares dependencies but no package-lock.json or yarn.lock is present. Builds are non-reproducible and may break across environments. Low — Minimal test coverage: Only 2 test files found across 200 source files. Core logic (generation, dictation, API client) is untested, increasing regression risk. Low — No backend code in repo: The API models and client suggest a separate backend service. This repo is a frontend-only app; deployment requires a backend not included here. Low — CI present but limited: GitHub Actions runs CI and builds Windows releases, but no linting or type-checking is visible in the workflow files.

The Bottom Line

Voicebox is a well-structured frontend for a local voice studio, with a clean component hierarchy and generated API client. It solves a real gap—combining generation and dictation offline—but the lack of lockfiles and near-zero test coverage make it risky for production use. Suitable for developers exploring local voice AI, not for teams needing reliable, maintainable software.
