The Problem

Job‑seeker workflows are fragmented across noisy job boards, manual scraping tools, and opaque AI services that hide ranking logic. Users need a single, locally‑run environment that can ingest listings, filter out low‑value leads, rank fit against a personal profile, and produce ready‑to‑send application assets without sending data to external servers.

What This Does

JustHireMe is a desktop‑first workbench that stitches together three layers:

Frontend UI – a React/Tauri application (src/App.tsx, src/views/.tsx) that visualises pipelines, graphs, and job cards. The UI is built with Vite (vite.config.ts) and packaged by Tauri (src-tauri/tauri.conf.json). Python side‑car API – a FastAPI‑style service (backend/main.py) exposing endpoints used by the UI. Core agents live under backend/agents/ (e.g., scraper, scoringengine, generator). Data persistence is handled by a Kuzu graph (backend/graph/) and LanceDB vectors (backend/models/schema.py). Cross‑process glue – Tauri’s Rust bridge (src-tauri/src/lib.rs, src-tauri/src/main.rs) launches the Python process, forwards WebSocket traffic (src/hooks/useWS.ts), and bundles required runtimes (src-tauri/resources/).

Key files illustrate the pipeline: backend/agents/leadintel.py gathers raw listings, backend/agents/qualitygate.py filters them, backend/agents/scoringengine.py computes deterministic scores, and backend/agents/generator.py produces PDFs.

How To Use It

Setup

Install Node tooling (npm is declared in package.json) npm ci # installs UI and Tauri deps Install Python deps (uv is recommended; fallback to pip) uv sync --frozen # reads backend/pyproject.toml Install Tauri’s system requirements (see Tauri docs)

The repo supplies a .env.example; copy to .env and fill any required API keys (e.g., OpenAI). No other secret files are present.

Build & Run

Build the UI and embed the Python sidecar npm run tauri dev # defined in package.json scripts (via vite + tauri) Or run the backend alone for API testing uv run backend/main.py

The UI entry point is src/main.tsx; the Python entry point is backend/main.py. The Tauri config (src-tauri/tauri.conf.json) points to backend/uv.lock for the side‑car binary.

Configuration

backend/data/profileschemaexample.json defines the user profile schema used for matching. backend/data/selectors.json holds selector rules for source adapters. Runtime settings live in src/settings/.tsx and are persisted locally (keychain integration is TODO).

Real‑World Use

A solo developer looking for AI‑focused roles could: Populate profileschemaexample.json with their résumé, skills, and preferred locations. Add a LinkedIn API token to .env. Run npm run tauri dev; the UI shows a Pipeline view where new leads appear. Accept a lead, click Generate, and receive a PDF cover letter and résumé tailored to that posting.

The process stays on the workstation; no job data leaves the machine.

Code Health & Issues

Med – Hard‑coded file paths – several agents reference backend/data/*.json relative to the repo root; moving the repo may break them (backend/agents/leadintel.py). Low – Missing type hints – many Python modules lack type annotations, reducing IDE support and static analysis reliability. Low – Incomplete secret management – API keys are stored in plain .env; no OS keychain integration yet (mentioned in README). Low – Limited test coverage – 10 test files exist, but core agents (scoringengine, generator) have no dedicated unit tests. Low – CI only builds – GitHub Actions (.github/workflows/ci.yml) runs lint and build but does not execute the Python side‑car tests; integration risk remains.

Overall the repository includes a lockfile (package-lock.json, uv.lock), a CI pipeline, and a README with clear start‑up instructions, indicating reasonable baseline hygiene.

The Bottom Line

JustHireMe delivers a functional, locally‑run job‑search workbench with a clear separation between UI (React/Tauri) and AI‑driven backend (Python agents). It is usable for individual power users or small teams willing to manage the local runtime and contribute missing tests or secret handling. Production‑grade adoption will require better test coverage, robust secret storage, and tighter path handling, but the core architecture is sound and extensible.
