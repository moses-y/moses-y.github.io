shepherd

A runtime substrate that turns an agent's execution into a reversible, Git-like trace, so meta-agents can observe, fork, replay, and revert any run. Couples agent and environments in a copy-on-write fork ~5x faster than docker commit, with ~95% KV-cache reuse on replay. Framework built for meta-agents to supervise, optimize, and train other agents

The Problem

Agent runs are black boxes. When an agent writes files, calls APIs, or modifies state, there is no way to inspect, roll back, or replay that execution. Debugging requires re-running from scratch, and supervision requires trusting the agent's output without review. Docker containers are too slow for checkpointing, and Git snapshots capture only files, not execution state.

What This Does

Shepherd records agent execution as a reversible, Git-like trace. The core mechanism lives in commons-vcs/src/commonsvcs/ — a version-controlled substrate that captures filesystem changes, environment state, and execution checkpoints. Copy-on-write forks run ~5x faster than docker commit, and KV-cache reuse hits ~95% on replay.

The system couples agents and environments at the runtime level. A task in docs/src/shepherd/tutorials/firstapp/app.py is a Python function with no body — the signature and docstring define the contract, and the agent fills it at runtime. Workspace outputs are proposals; nothing touches the host filesystem until explicitly accepted. Permissions are enforced via OS-level grants (macOS Seatbelt, Linux Landlock) through containers/sandbox/Dockerfile.

Real-World Use

An agent writes code, modifies a repo, and produces artifacts. The run is recorded as a durable trace. A meta-agent inspects the trace, forks it at any checkpoint, replays with modifications, and either accepts or discards the output. This enables workflows like automated PR review (docs/src/shepherd/workflows/fixtures/pr-review.yaml), supervised code generation, and agent training pipelines where runs are used as training data.

The Bottom Line

Shepherd solves a real problem — making agent execution inspectable and reversible — with a novel approach that outperforms Docker-based checkpointing. The codebase is well-structured and the documentation is thorough for an alpha project. It is not production-ready; APIs are unstable and the tool is actively evolving. Teams building meta-agent systems or agent training pipelines should evaluate it now for design feedback, but wait for a stable release before depending on it.
