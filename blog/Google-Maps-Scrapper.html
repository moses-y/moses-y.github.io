Google Maps Scrapper

Abstract

This code is used to perform web scraping and data extraction from Google Maps. It is particularly designed for obtaining information about businesses, including their name, address, website, phone number, reviews, and more.

The Problem

Engineers needing structured business data from Google Maps face manual collection bottlenecks or brittle scrapers that break when DOM selectors shift. This repo addresses the need for automated extraction of business listings, contacts, reviews, and operational details without building a scraping pipeline from scratch.

How To Use It

Setup: Clone the repo verbatim:

git clone https://github.com/moses-y/Google-Maps-Scrapper.git
cd Google-Maps-Scrapper
pip install -r requirements.txt
playwright install

Configuration: No environment variables or API keys are documented. The script relies on a visible Chrome/Chromium installation and the Playwright browsers installed via playwright install. The requirements.txt pins specific versions of pyee, pytz, et-xmlfile, numpy, and pandas, but without a lockfile installs may vary.

Running it: Invoke the entry point with search parameters:

python main.py -s "Turkish Restaurants in Toronto Canada" -t 20 -o custom_output.csv
  • -s / --search: Google Maps search query
  • -t / --total: Number of results to scrape
  • -o / --output: Output CSV path (defaults to result.csv)
  • --append: Append to existing CSV instead of overwriting

Real-World Use

A market researcher wants 50 business listings for "coffee shops in Seattle" to analyze review sentiment and operating hours. They run python main.py -s "Coffee shops in Seattle" -t 50 -o seattle_coffee.csv. The script launches a browser, navigates Google Maps, extracts name, address, phone, review count, rating, and hours per listing, then appends all rows to seattle_coffee.csv. The researcher can later load the CSV into a BI tool. If Google Maps updates its DOM, the XPaths in main.py must be adjusted — the script offers no self-healing mechanism.

The Bottom Line

This repo delivers a functional Google Maps scraper with minimal setup — ideal for one-off data extraction or prototyping, but the pinned dependencies, absence of a lockfile, and unmaintained code path make it unsuitable for production without vetting. The deep nesting in main.py and lack of tests mean any DOM change or dependency upgrade requires careful manual review. Use it for ad-hoc scraping; for ongoing data pipelines, invest in a maintained scraper or allocate time to refactor the nesting and add version pinning.
