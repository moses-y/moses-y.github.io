forge3d

Abstract

Rust‑first, cross‑platform wgpu/WebGPU renderer exposed to Python for fast, headless 3D rendering. Built in Rust, shipped as Python wheels.

The Problem

The forge3d repository addresses the need for fast, headless 3D rendering in various applications, including geographic information systems (GIS), computer-aided design (CAD), and video game development. It provides a Python-first interface to a Rust-based, WebGPU-accelerated rendering engine, enabling efficient and interactive visualization of complex 3D scenes.

What This Does

The forge3d repository offers a range of features, including interactive terrain viewing, raster overlays, vector overlays, labels, and camera automation. It also supports point-cloud loading, COG access, and native/offscreen rendering. The examples/ directory contains a collection of runnable scripts demonstrating these features, such as bosniaterrainlandcoverviewer.py and californiacigarsmokedemo.py. The docs/ directory provides extensive documentation, including a Quickstart guide and an API Reference.

Real-World Use

A practical scenario for using forge3d is in the development of a GIS application for visualizing and analyzing terrain data. For example, a user could utilize the openviewerasync() function to create an interactive 3D viewer, load a GeoTIFF file as a terrain overlay, and then use the setzscale() and setorbitcamera() methods to customize the viewer's perspective.
