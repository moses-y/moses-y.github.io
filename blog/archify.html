archify

Any agent Skill: generate beautiful architecture diagrams with dark/light theme toggle and PNG/JPEG/WebP/SVG export

Forked from tt-a1i/archify

The Problem

Teams waste time manually drawing architecture diagrams that fall out of date, or they paste static screenshots into docs that don't match the reader's dark/light theme preference. Existing diagram tools require desktop apps, produce blurry exports, or can't be iterated by describing changes in natural language.

What This Does

Archify is an agent skill for Claude, Codex CLI, and opencode that converts plain-English descriptions into self-contained HTML diagrams. It produces five diagram types: architecture, workflow, sequence, data flow, and lifecycle. Each renderer lives in archify/renderers/ with shared utilities in shared/cli.mjs, shared/geometry.mjs, and shared/validator.mjs.

The generated HTML files have zero dependencies. They include a built-in dark/light theme toggle, clipboard PNG copy, and native-resolution PNG/JPEG/WebP/SVG export at up to 4x source resolution. SVGs ship with both theme variables and @media (prefers-color-scheme) so they adapt automatically when embedded in GitHub READMEs. Input schemas in archify/schemas/ validate each diagram type before rendering.

Real-World Use

A developer describes a deployment pipeline: "User submits a request -> Agent plans -> Approval Gate if needed -> Tool Call -> Trace Log -> Final Reply." Archify produces a workflow diagram with swimlanes, semantic colors, and secondary paths. The team drops the SVG into a runbook, and it matches each reader's system theme without additional markup.

Code Health & Issues

The codebase appears well-structured with no major red flags. Evidence of discipline: 5 test files in archify/test/, GitHub Actions CI configured at .github/workflows/ci.yml, a CHANGELOG.md, and MIT license. Low - Limited test coverage: 5 test files for 6 renderers and shared modules. render-architecture.mjs and render-workflow.mjs have no dedicated test files. Edge cases in complex layouts may surface in production. Low - No dependency lockfile validation: package-lock.json is present but no Dependabot or Renovate config found in .github/. Dependencies could drift without automated alerts. Med - Input validation relies on JSON Schema files (schemas/*.schema.json), but the validator at shared/validator.mjs could still produce opaque error messages for malformed user input. CLI users may find debugging cryptic.

The Bottom Line

Archify solves a narrow but real problem: generating presentation-quality technical diagrams from natural language with zero external tools. The theme-aware SVG export is genuinely useful for documentation. It's best suited for teams that already use Claude or Codex CLI and want to produce diagrams as part of their workflow. Teams needing extensive customization or non-technical diagram types should look elsewhere.
