SciAgent Skills

197 bioinformatics & life science skills for Claude Code and AI agents — BixBench 92.0% accuracy. RNA-seq, single-cell, drug discovery, proteomics, and more. Powers OmicsHorizon.

Forked from jaechang-hits/SciAgent-Skills

The Problem Bio‑informatics teams spend weeks curating command‑line arguments, data‑format quirks, and best‑practice notes for each tool (e.g., STAR, DESeq2, scanpy). When an AI coding assistant lacks that domain knowledge, it generates broken pipelines, forcing developers to intervene manually. The gap is a reusable, structured knowledge base that an agent can read and apply without bespoke fine‑tuning.

What This Does SciAgent‑Skills supplies 199 self‑contained markdown skill definitions (e.g., skills/genomics-bioinformatics/rnaseq/deseq2-differential-expression/SKILL.md). Each file includes:

a concise description, runnable code snippets, parameter tables, and troubleshooting tips.

The repository also ships a Claude‑compatible plugin manifest (.claude-plugin/plugin.json) and a registry (registry.yaml) that map skill names to their locations. The small Python helper suite (scripts/validateregistry.py, scripts/blindknowledgetest.py) validates that the registry is syntactically correct and that the benchmark data (blindtestresults.csv) matches expectations.

How To Use It Create a Python environment – the project uses Pixi (see pixi.toml / pixi.lock). pixi install # resolves the conda/pip dependencies pixi run python -m pip install -e . # editable install (no package, but registers scripts) Validate the skill registry – run the supplied script to ensure all SKILL.md files are reachable. pixi run python scripts/validateregistry.py Add the plugin to Claude Code – copy the .claude-plugin directory into the Claude plugin path or reference it via the marketplace URL contained in marketplace.json. The plugin JSON points to the registry.yaml file, which the agent reads at runtime. Invoke a skill – within Claude Code, request a task such as “run DESeq2 differential expression”. The agent will locate the matching entry in registry.yaml, retrieve the code block from skills/genomics-bioinformatics/rnaseq/deseq2-differential-expression/SKILL.md, and execute it in the current environment. Run the benchmark (optional) – to reproduce the reported BixBench score: pixi run python scripts/blindknowledgetest.py blindtestresults.csv

All CI steps are defined in .github/workflows/validate.yml, which runs the validation script and the test suite on each push.

Real‑World Use A research group automates an RNA‑seq analysis pipeline. After installing the skill set, a data‑science engineer writes a short prompt to Claude Code:

“Using the DESeq2 skill, compare condition A vs B in counts.tsv and output a volcano plot as volcano.png.”

Claude Code retrieves the snippet from SKILL.md, substitutes the file path, runs the R code via the system R interpreter, and returns the plot. The entire step is reproducible without hand‑typing any R commands, reducing analyst time from hours to minutes.

Code Health & Issues

Tests – Medium – 9 test files exist, but they only cover the validation scripts; the markdown skills themselves have no automated verification. Dependency Hygiene – Low – Pixi manages Python packages, yet no explicit lock for external tools (e.g., R, Java) that many skills require, which could cause runtime failures on fresh systems. Documentation – Low – The README explains the concept and benchmark but lacks a quick‑start guide; users must infer commands from pixi.toml and scripts. License – Low – The repository includes LICENSE (CC‑BY‑4.0), satisfying legal reuse, but no SPDX header in source files. CI Coverage – Low – The GitHub Actions workflow validates the registry but does not lint markdown or test code snippets, leaving syntax errors undetected.

Overall, the codebase shows no structural red flags; the layout is clear, and CI runs successfully on push.

The Bottom Line SciAgent‑Skills delivers a well‑organized, markdown‑based knowledge base that materially improves AI coding agents on bio‑informatics tasks (92 % BixBench accuracy). It is ready for teams that already use Claude Code or a similar markdown‑aware agent and can tolerate the manual step of installing external toolchains (R, Java, etc.). The primary gaps are limited automated testing of the skill snippets and sparse start‑up documentation; addressing these would make adoption smoother for solo developers.
