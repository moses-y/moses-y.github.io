Osintgraph

Abstract

About Osintgraph is an open-source tool that collects Instagram data, followers, and followees, storing them in Neo4j. It helps you easily map and analyze a target's social network, revealing interests, connections, and affiliations for effective OSINT.

The Problem

Investigating an Instagram target's social network manually is slow and error-prone. Public data—followers, followees, posts, comments, likes—is scattered across API responses and HTML, and connecting the dots between who interacts with whom requires significant manual effort. Osintgraph addresses this by collecting that data into a graph database and providing an AI agent to query it in natural language.

What This Does

Osintgraph is a Python CLI tool that scrapes public Instagram data and stores it in Neo4j as a property graph. The core collection logic lives in src/osintgraph/instamanager.py, which handles session management via getsession.py and credential storage through credentialmanager.py. The Neo4j persistence layer is in neo4jmanager.py, defining a schema of Person, Post, and Comment nodes with relationship types (FOLLOWS, POSTED, COMMENTEDON, LIKED).

Beyond collection, the repo includes an AI agent (src/osintgraph/osintgraphagent/osintgraphagent.py) that translates natural-language questions into Cypher queries and template-driven analyses. The agent uses tools defined in osinttools/neo4jtools.py and prompt templates in osintprompts/. A CLI entry point in src/osintgraph/cli.py exposes commands for setup, data discovery, exploration, and agent interaction.

How To Use It

The project is Python-based with dependencies declared in pyproject.toml. No lockfile is present, so install with pip install -e . or uv sync (if uv is preferred). Setup requires a Neo4j instance and Instagram credentials.

Configuration: Credentials are stored via the setup command, which handles Instagram session cookies and Neo4j connection details. Environment variables for API keys (e.g., LLM provider) would go in a .env file, though the repo doesn't document exact names.

Running it: Install pip install -e .

Configure credentials and Neo4j connection

osintgraph setup

Collect data for a target

osintgraph discover <username> osintgraph explore <username>

Launch the AI agent for analysis

osintgraph agent

The README documents these commands, and src/osintgraph/main.py wires them to the CLI.

Real-World Use

An investigator targeting a person of interest runs osintgraph discover targetuser to pull their public profile, followers, and followees into Neo4j. They then run osintgraph explore targetuser to fetch posts and comments. With the graph populated, they query the agent: "Who are the mutual followers between targetuser and personx?" The agent translates this to a Cypher query, executes it against Neo4j, and returns the answer—turning days of manual cross-referencing into minutes.

Code Health & Issues

Medium - No tests: No test files exist. The scraping logic in instamanager.py and the agent's query generation are complex and untested; regressions are likely. Medium - No CI/CD: No .github/ or CI config. Nothing gates merges on build or lint checks. Low - No lockfile: pyproject.toml declares dependencies but no pinned versions, so builds aren't reproducible. Low - Credential handling: credentialmanager.py stores Instagram session data—verify it encrypts at rest and doesn't log credentials. Low - Scraping fragility: Instagram's HTML/API changes frequently; the code in dataextractors.py and fetch_urls.py will break without active maintenance.

The Bottom Line

Osintgraph is a functional, well-structured OSINT tool for Instagram network analysis, with a thoughtful graph schema and a genuinely useful AI agent layer. It's not production-grade—no tests, no CI, no lockfile—but for a consultant or investigator running controlled collection efforts, it's a solid foundation. Expect to add your own test coverage and pin dependencies before relying on it.
