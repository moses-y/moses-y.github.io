The polyhierarchy design allows the same note to appear under multiple parents without duplication. Three crates compose the system: crates/liwe/ provides the core graph, markdown parsing, and document model; crates/iwe/ implements the CLI with commands for retrieve, export, find, normalize, and stats; crates/iwes/ delivers an LSP server for editor integration (VS Code, Neovim, Zed, Helix). How To Use It Setup: Install via cargo install iwe (project published to Crates.io) or build from source with cargo build --release in the repository root. The Cargo.lock ensures reproducible builds.

Configuration: No configuration files or environment variables are required for basic operation. Notes are authored as markdown files in a directory; inclusion links create hierarchical relationships automatically.

Running it: CLI commands invoke from crates/iwe/src/main.rs. Example: iwe retrieve <topic> fetches notes matching a topic with full context (children, parents, related). iwe export generates structured output. The LSP server starts via crates/iwes/src/main.rs and registers with your editor for search, definition, references, and refactoring operations.
