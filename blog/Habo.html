The Problem

Most habit trackers either harvest user data or require a cloud account with plaintext storage. Users who want privacy must choose between sync and security. Habo targets this gap: a tracker that works offline, syncs only encrypted data, and can be self-hosted on Supabase.

What This Does

Habo is a Flutter app (iOS/Android) implementing a zero-knowledge sync layer. Data is encrypted client-side using a master password before transmission. The android/app/src/main/java/com/pavlenko/Habo/ directory contains platform-specific widgets (HaboWidget.kt) and background workers (WidgetUpdateWorker.kt). The iOS counterpart lives in ios/HaboWidget/HaboWidget.swift. Sync configuration uses environment variables (.env.example), and deployment is automated via fastlane/. Offline-first operation is the default; sync is optional and fully opt-in.

Real-World Use

A user installs Habo, creates habits, and optionally sets a master password. When sync is enabled, each check-in is encrypted locally and pushed to the user’s own Supabase instance. On a new device, the same master password decrypts the data. The home-screen widgets (Android and iOS) allow quick check-ins without opening the app.

The Bottom Line

Habo is a well-conceived privacy-first habit tracker with genuine differentiators: zero-knowledge sync and self-hosting. The feature set is solid, and the documentation is clear. However, the complete absence of tests is a notable weakness for a production app handling user data. Suitable for privacy-conscious individuals and small teams who can accept some risk, but not recommended for critical or enterprise use without adding test coverage.
