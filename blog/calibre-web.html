calibre web

:books: Web app for browsing, reading and downloading eBooks stored in a Calibre database

Forked from janeczku/calibre-web

The Problem

Running a personal ebook library across multiple devices is cumbersome. Calibre itself is a desktop application, so accessing your collection from a phone, tablet, or e-reader requires manual file transfers or third-party sync tools. There's no built-in web interface for browsing, reading, or downloading books from a Calibre database remotely.

What This Does

Calibre-Web is a self-hosted web application that serves your existing Calibre library over HTTP. It reads directly from a Calibre SQLite database (cps/db.py) and presents a responsive Bootstrap 3 interface for browsing, searching, and reading ebooks in-browser. The application handles user authentication (cps/MyLoginManager.py, cps/cwlogin/), OPDS feeds for e-reader apps (cps/opds.py), and Kobo device synchronization (cps/kobo.py).

The cps/ directory contains the core application: route handlers (cps/basic.py, cps/admin.py), metadata providers (cps/metadataprovider/), ebook format converters (cps/converter.py, cps/epub.py), and a background task scheduler (cps/services/backgroundscheduler.py). Entry points are cps/cli.py and cps/main.py. The application ships with CJK character mapping files (cps/static/cmaps/) for proper ebook rendering in those languages.

Real-World Use

Deploy on a small server (Raspberry Pi or VPS) pointed at your Calibre library directory. Users authenticate via the web UI or OAuth (cps/oauth.py), browse by author/tag/series, read EPUBs in-browser, or download books. Kobo users can sync wirelessly. For a single-user setup, the "magic link" feature (cps/remotelogin.py) generates a tokenized URL for easy e-reader access.

The Bottom Line

Calibre-Web solves a real problem well: exposing a Calibre library to the web with a clean UI and solid feature set (OPDS, Kobo sync, metadata providers, user management). It's mature and widely used (17k+ stars on the upstream). However, the complete absence of tests and CI makes it risky for production environments where reliability matters. Best suited for personal or small-team use where you can tolerate manual upgrades and occasional breakage.
