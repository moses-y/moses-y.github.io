The Problem

Developers using Claude Code, Gemini CLI, or OpenAI Codex need a compact, reproducible set of “skill” artifacts (templates, loops, and helper scripts) that encode best‑practice engineering processes. Without a shared repository, each user must recreate these patterns manually, leading to inconsistency and wasted effort.

What This Does

lich-skills bundles a curated library of markdown‑based “skills” that each describe a concrete workflow together with any supporting scripts. The top‑level index.js exports a simple dispatcher that can load a skill by name, while the skills/ folder holds the actual content:

skills/spec-driven-dev/ – a full SDLC loop with spec, plan, build, test, review, ship artifacts (e.g., templates/plan.md, templates/review.md). skills/debug-hypothesis/ – a scientific‑method debugging loop with a concise checklist (SKILL.md). skills/wiki-aggregate/ – an agentic aggregation pattern that produces provenance‑rich packs (brief.md, sources.tsv).

Supporting scripts live alongside the markdown, e.g., skills/nano-banana/scripts/generateimage.py and skills/tavily-search/scripts/search.py. The repository also includes CI (.github/workflows/ci.yml) and a pre‑commit hook (scripts/pre-commit).

How To Use It

Setup

Install Node dependencies (npm is implied by package.json) npm ci

Install Python helpers used by some skills

python -m venv .venv source .venv/bin/activate pip install -r requirements.txt # (if a requirements file exists; otherwise install needed packages manually)

Configuration

No global configuration file is shipped. Individual skills that need API keys (e.g., tavily-search) expect the key in an environment variable referenced in their Python scripts. Create the variable before invoking the skill, e.g. export TAVILYAPIKEY=….

Running a Skill

The entry point is index.js. It accepts a skill identifier as a command‑line argument and prints the rendered markdown or executes any bundled script.

Show the spec‑driven‑dev workflow

node index.js spec-driven-dev

Run the nano‑banana image generator (Python helper)

node index.js nano-banana # will invoke generateimage.py internally

If a skill includes a shell script (e.g., skills/spec-driven-dev-v2/scripts/task-lint.sh), the dispatcher forwards the call to that script; otherwise it simply outputs the SKILL.md content.

Extending

Add a new skill under skills/<name>/ with a SKILL.md and optional scripts/ directory. Register the name in index.js (a short case or map entry) to make it discoverable.

Real‑World Use

A software team can embed the spec‑driven‑dev skill into their CI pipeline to enforce the six‑phase loop. Example snippet for a GitHub Action step: name: Run Spec‑Driven Dev Check run: node index.js spec-driven-dev | grep -q "EXITCRITERIAPASSED"

The step fails the workflow if the rendered checklist indicates missing criteria, ensuring every PR meets the defined gate before merging.

The Bottom Line

lich-skills delivers a well‑organized collection of engineering “skills” that can be invoked from a simple Node dispatcher, making it useful for teams that already rely on Claude/Gemini/Code models and want reusable process templates. To adopt it safely, the client should add clear CLI documentation, lock down Python dependencies, and extend test coverage for the dispatcher. If those gaps are addressed, the repo is a practical, low‑overhead knowledge‑base for disciplined development workflows.
