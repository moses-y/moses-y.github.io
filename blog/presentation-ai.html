The Problem

Many teams need to produce polished slide decks quickly but lack a lightweight tool that balances AI‑generated content with full design control. Existing SaaS alternatives either lock customization behind paywalls or force a rigid outline‑only workflow, leaving designers to manually re‑format every slide.

What This Does

presentation‑ai is a Next.js‑based full‑stack app that generates presentation slides from an AI‑driven outline. Core logic lives in src/ai/agents/presentation/createAgent.ts and src/ai/tools/presentation/tools.ts, which coordinate content creation, image generation, and chart rendering. The theming system is split into creation steps under src/components/notebook/presentation/components/theme/create-theme/, including CompactBackgroundSelector/index.tsx, font-step/index.tsx, and associated utility files (utils.ts, types.ts). Presentation editing uses the Plate editor (src/components/notebook/presentation/editor/components/EditablePlate.tsx) and custom chart elements such as bar-graph.tsx, area-chart.tsx, and chart-data-editor/index.tsx. Exported actions under src/app/actions/presentation/ handle fetch, generate, and favorite operations, while API routes under src/app/api/presentation/ expose endpoints for slide generation, outline creation, and diagram rendering.

How To Use It

Setup Install dependencies with pnpm install (the repo uses pnpm as declared in package.json). Copy .env.example to .env and fill the required variables: OPENAIAPIKEY, DATABASEURL, and any Together AI or Ollama endpoints. The example file is present at the repo root. Run Prisma migrations to create the PostgreSQL schema: pnpm prisma migrate deploy (Prisma schema is at prisma/schema.prisma). The seed script at prisma/seed/seed.ts can populate initial data.

Running the app

Start the development server with pnpm dev (script defined in package.json). The entry point is src/app/page.tsx, which renders the landing UI. To create a new presentation, navigate to /presentation/create (src/app/presentation/create/page.tsx), provide a topic, choose a theme, and submit. The createAgent.ts function orchestrates outline generation, after which the UI displays a live preview using SlidePreview.tsx and SlideGenerationContext.tsx.

Custom themes

Use the theme creator at src/components/notebook/presentation/components/theme/create-theme/ to define colors, fonts, and background images. The stepper component CreateThemeStepper.tsx guides through ColorSettingsPanel.tsx, FontPickerField.tsx, and CompactBackgroundSelector/index.tsx. Exported themes can be saved via theme-actions.ts and reused across projects.

Real‑World Use

A marketing team can spin up a product launch deck in under five minutes: a designer types a brief prompt, the agent generates an outline, the team reviews and edits it in the Plate editor, and the final deck is exported as PPTX via the generate-slide-image API route (src/app/api/presentation/generate-slide-image/route.ts). Infographics such as bar charts are inserted through bar-graph.tsx, and the presentation can be shared publicly using the share route src/app/share/presentation/[id]/page.tsx.

Code Health & Issues

No CI/CD pipeline – the .github/ directory contains only FUNDING.yml; there is no GitHub Actions workflow for automated builds or tests, meaning changes can be merged without verification. Limited test coverage – only two test files are present; critical paths such as agent orchestration and Prisma interactions lack unit or integration tests. Dependency hygiene – a patch file patches/@ai-sdk_langchain@2.0.122.patch suggests a manual fix for a Langchain SDK version; no automated dependency audit (e.g., pnpm audit) is evident in the workflow. Environment exposure – .env.example is committed to the repo, which may inadvertently reveal placeholder keys if not replaced before push. Separation of concerns – many UI components live under src/components/notebook/presentation/, but some action logic is duplicated across src/app/actions/presentation/ and API routes, making future refactors harder.

The Bottom Line

presentation‑ai delivers a functional, AI‑driven slide generator with extensive theming and export options, making it a solid starting point for teams that need rapid slide production without sacrificing customization. However, the absence of CI/CD, sparse test suite, and exposed example env vars raise production‑readiness concerns; it is best suited for internal prototypes, hackathons, or early‑stage products where a quick MVP outweighs strict engineering gates. Teams comfortable managing their own deployment pipeline and adding test coverage will get the most value.
