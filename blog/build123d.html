The Problem

Traditional CAD scripting tools (OpenSCAD, CadQuery) either lack true parametric modeling or force users into a stateful, imperative style that makes complex designs hard to maintain. Engineers who want to write CAD models as code often end up fighting the API instead of expressing geometry directly.

What This Does

build123d is a Python-based parametric boundary representation (BREP) modeling framework for 2D and 3D CAD, built on the Open Cascade geometric kernel. It provides explicit Edge, Wire, Face, Solid classes with well-defined operations, plus a builder pattern (BuildPart, BuildSketch) for imperative modeling. The library supports algebraic, operator-driven syntax like obj += subobj and Plane.XZ Pos(X=5) Rectangle(1, 1) for composable design logic.

The repo is essentially the documentation and infrastructure layer — 182 of 200 files live in docs/, with examples rendered as SVG assets (docs/assets/generalex1.svg through general_ex36.svg). The actual Python source is absent from this snapshot; what's present is the CI pipeline (.github/workflows/ with test.yml, lint.yml, type.yml, coverage.yml), docs, and config files. The README documents usage patterns and the docs/ folder contains extensive .rst tutorials covering assemblies, algebra definitions, and advanced features.

How To Use It

The README documents installation via PyPI and usage via wildcard import:

pip install build123d

from build123d import *

The primary workflow is writing standalone Python scripts that construct 3D models and export them. The docs (docs/advanced.rst, docs/assemblies.rst) show the two main API styles: the builder pattern with BuildPart/BuildSketch, and the algebraic style using operators and Pos, Rot, Plane transforms. Export to STEP format (for FreeCAD/SolidWorks) is supported.

Real-World Use

A typical workflow: design a mechanical bracket parametrically, where dimensions are Python variables. Change one dimension, re-run the script, and get an updated STEP file for CNC machining or a mesh for 3D printing. The library handles the BREP math; you write the design intent. The docs/assets/examples/ folder shows outputs ranging from toy trucks to heat exchangers.

The Bottom Line

build123d is a serious, well-maintained CAD library with strong documentation and a real user base (2,840 stars upstream). The algebraic API is a genuine differentiator — it reads like math, not like a stateful API. For engineers who prefer Python over OpenSCAD's DSL or FreeCAD's GUI, this is worth evaluating. The main caveat: this snapshot contains no source code, so treat it as documentation of the project's surface, not its internals.
