The Problem Salon and spa operations often require coordinating bookings, service catalogs, and customer histories across multiple locations, yet many businesses still rely on fragmented spreadsheets or disjointed tools. This repository provides a React-based admin panel (Admin Panel/) intended to centralize those operations, but the codebase is split between a management dashboard and a separate ML-driven skincare recommendation subsystem, which creates integration gaps for a unified workflow.

What This Does The Admin Panel/ directory (155 files) constitutes a React.js frontend designed for multi-salon dashboard management, service tracking, and booking calendars, with Firebase referenced as the backend for real-time updates. alongside it, AI Sakincare Recommandation/ (45 files) houses Python-based ML models (mlmodelflask/app.py, mlmodelAWS_Lambda/app.py) for facial skin analysis, supported by export.pkl, recommendation.json, and requirements.txt. Together they aim to combine appointment management with AI-powered skin diagnostics, though the two halves currently operate as separate sub-projects with no documented integration layer.
