The Problem: AI coding agents lose all session context between runs. Each new session forces re-explanation of architecture, re-discovery of bugs, and re-teaching of preferences. Static files like CLAUDE.md and .cursorrules overflow and go stale. The agentmemory repository provides a persistent, searchable memory layer built on iii-engine, designed to capture, compress, and inject project context across agent sessions.

What This Does: The system automatically captures every tool use, file edit, test run, and error via hooks in src/hooks/. Raw observations feed into LLM compression functions (src/functions/compress.ts, src/prompts/compression.ts) that produce structured facts, concepts, and narratives. A hybrid retrieval engine in src/state/hybrid-search.ts combines BM25, vector, and knowledge graph search (src/functions/graph-retrieval.ts, src/functions/smart-search.ts). Memory evolves through 4-tier consolidation (src/functions/consolidate.ts, src/functions/crystallize.ts, src/functions/summarize.ts, src/functions/consolidation-pipeline.ts) with versioning, staleness tracking, and auto-eviction (src/functions/evict.ts, src/functions/retention.ts). Privacy stripping occurs before storage (src/functions/privacy.ts). The MCP server (src/mcp/server.ts) exposes 41 tools and serves Claude Code, Cursor, Codex, Windsurf, and any MCP client simultaneously.

Running it: Invoke the CLI from src/cli.ts via npx @agentmemory/agentmemory or start the MCP server directly with tsx src/mcp/server.ts or docker-compose up.
