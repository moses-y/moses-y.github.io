The Problem

This repository addresses the gap between learning Python data science libraries and applying them to real-world business problems. Most tutorials stop at isolated library examples, and most project repos lack the breadth to show how NumPy, Pandas, visualization, and machine learning fit together in actual workflows. This repo attempts to bridge that by pairing library tutorials with applied projects across finance, insurance, and e-commerce.

What This Does

The repo is a mixed collection of Jupyter notebooks and Python scripts organized by topic. Python Libraries For Data Science - NumPy.ipynb and Python Libraries For Data Science - Pandas..ipynb cover core libraries, while Python Libraries - Pandas & Seaborn/Python Libraries for Data Visualization..ipynb and Python Library/Python Libraries- Visualization with Matplotlib.ipynb handle visualization.

The applied projects are the more substantial content. Generalised Linear Models in Insurance Motor Claims/Generalised Linear Models on Motor Insurance Claims Project..ipynb tackles actuarial modeling, Linear Regression-Decision Tree Models/8. DS- Stock Price Prediction with Machine Learning.ipynb does financial forecasting, and Amazon Product Review Sentiment Analysis/12. Amazon Product Reviews Sentiment Analysis with Machine Learning..ipynb covers NLP. Britam Data Science Project/20. Web Scrapping Britam website for Products Chatbot.ipynb shows web scraping, and Streamlit Projects/StreamlitApp1.py is a standalone Streamlit app.

How To Use It

Setup: No dependency files exist—no requirements.txt, environment.yml, or pyproject.toml. You'll need to install Jupyter, NumPy, Pandas, Matplotlib, Seaborn, scikit-learn, and Streamlit manually via pip install.

Configuration: None required. No environment variables, API keys, or config files are present.

Running it: Open the notebooks in Jupyter (jupyter notebook from the repo root) and execute cells sequentially. The Streamlit app runs with streamlit run Streamlit Projects/StreamlitApp1.py. There is no CLI or main script.

Real-World Use

A data analyst building a churn model could start with the Pandas and visualization notebooks to get the data handling patterns, then adapt the GLM notebook's approach from Generalised Linear Models in Insurance Motor Claims/Generalised Linear Models on Motor Insurance Claims Project..ipynb for their own regression problem. The Streamlit app provides a template for turning a trained model into a shareable web interface.

The Bottom Line

A reasonable educational resource for someone learning Python data science through worked examples. The insurance GLM and sentiment analysis notebooks are the most substantive content. It is not production code—no tests, no packaging, no deployment story—so treat it as a learning reference rather than something to integrate into a system. Suitable for students or analysts early in their data science journey, not for teams needing maintainable, tested code.
