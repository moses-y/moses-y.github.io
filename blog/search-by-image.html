search by image

Browser extension for reverse image search, available for Chrome, Edge and Safari

Forked from dessant/search-by-image

The Problem

Journalists, researchers, and online shoppers need to find the source, duplicates, or higher-resolution versions of images across the web. Manually opening multiple search engines and re-uploading the same image wastes time and breaks workflow continuity.

What This Does

search-by-image is a browser extension that lets users right-click any image on a webpage and send it to over 30 reverse image search engines. The src/engines/ directory contains individual engine modules (e.g., googleImages.js, tineye.js, baidu.js), each handling the specific URL construction and request format for that service. The src/background/main.js file manages the extension's background processes, including context menu creation and communication between browser tabs and the action popup.

The extension is built as a multi-browser WebExtension, with manifest variants in src/assets/manifest/ for Chrome, Firefox, Edge, Opera, Safari, and Samsung. The UI components use Vue.js (see src/action/App.vue and src/options/App.vue), and the build pipeline uses Gulp (gulpfile.js) with Babel and PostCSS.

Real-World Use

A fact-checker sees a suspicious photo on a news site. They right-click, select "Search by Image," and the extension sends the image URL to Google Images, TinEye, Yandex, and Baidu simultaneously—each opening in a new tab. The journalist can then compare results across engines to determine if the image is original, edited, or previously debunked.
