The Problem The WHOOP 4.0 band collects biometric data, but users have limited control over their own data. This project aims to provide an open-source, local-first client to read and store biometric data from the WHOOP 4.0 band, giving users more control over their data.

What This Does The project provides a native iOS app (ios/) that collects biometric data from the WHOOP 4.0 band over Bluetooth LE and stores it locally on the device. The app uses a schema-driven decoder (protocol/whoop_protocol.json) to decode the data, which is shared with an optional self-hosted server (server/) for syncing and storing data. The project also includes reverse-engineering scripts (re/) and documentation (docs/) for development and research purposes.

Real-World Use For example, a user can use the iOS app to collect their heart rate data from the WHOOP 4.0 band and store it locally on their device. They can then sync this data with their self-hosted server, which can provide additional insights and analytics.
