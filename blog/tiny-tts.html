tiny tts

The Smallest English TTS Model with only 1M parameters

Forked from tronghieuit/tiny-tts

The Problem The development of text-to-speech (TTS) systems often requires significant computational resources, limiting their deployment on edge devices or in environments without dedicated graphics processing units (GPUs). This constraint hinders the widespread adoption of TTS technology in various applications.

What This Does The tiny-tts repository provides an ultra-lightweight English TTS model with only 1.6 million parameters, significantly reducing the computational requirements for speech synthesis. The model is implemented in Python, utilizing the torch and torchaudio libraries, and can be installed via PyPI or npm. The tinytts directory contains the core implementation, including the infer.py and models modules, which handle speech synthesis and model definition, respectively.

The repository also includes example usage scripts, such as app.py, which demonstrates how to use the tiny-tts model for speech synthesis. Additionally, the onnx directory contains pre-converted ONNX models, allowing for efficient deployment on various platforms.
