Memento-Skills: Let Agents Design Agents

Forked from Memento-Teams/Memento-Skills

The Problem

LLM agents today are frozen at deployment. Adaptation requires either retraining model weights or hand-writing new tools and prompts — both expensive and slow. Memento-Skills addresses this by letting an agent learn from live interactions and continuously rewrite its own skill library, without touching the underlying model parameters.

What This Does

Memento-Skills is a self-evolving agent framework. At its core is a read-write reflection loop: the agent routes a task to an existing skill or generates a new one, executes it, then reflects on the outcome and writes back to its skill memory — increasing a skill's utility score on success or rewriting the skill folder on failure.

The repo is organized into two main areas. builtin/skills/ contains 10 packaged skills (docx, pdf, pptx, xlsx, web-search, skill-creator, and others), each with a SKILL.md manifest plus Python scripts. The skill-creator skill is the meta-tool: it contains agents for analyzing, comparing, and grading skills, plus scripts like runloop.py, runeval.py, and packageskill.py that drive the creation pipeline. The 3rd/weixinsdk/ directory is a self-contained WeChat integration SDK with QR login, messaging, and media upload — presumably the IM interface layer.

Real-World Use

A support team deploys the agent with the WeChat SDK (3rd/weixinsdk/) as its IM frontend. Users ask it to generate a slide deck; the agent routes to the pptx skill, executes add_slide.py, and delivers the file. The reflection loop then scores the outcome — if the user requests revisions, the skill folder is rewritten to encode that preference for future runs. Over weeks, the agent's skill library accumulates domain-specific knowledge without any model retraining.

The Bottom Line

The core idea is sound: deployment-time learning via a skill memory is a practical alternative to fine-tuning. The built-in skill set is genuinely useful, and the self-improvement loop is well-conceived. However, the repo appears mid-refactor (the infra/ layer mentioned in the README is absent), lacks tests and CI, and has no clear install path documented. This is a promising research prototype for teams comfortable operating from source, not a drop-in production tool yet.
