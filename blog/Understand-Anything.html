Understand Anything

Graphs that teach > graphs that impress. Turn any code into an interactive knowledge graph you can explore, search, and ask questions about. Works with Claude Code, Codex, Cursor, Copilot, Gemini CLI, and more.

Forked from Egonex-AI/Understand-Anything

The Problem

Onboarding onto a large, unfamiliar codebase is slow and error-prone. Developers waste hours reading files linearly, guessing at dependencies, and piecing together architecture from scattered documentation. The cognitive overhead of mapping 200,000+ lines of code manually is a real productivity drain.

What This Does

Understand Anything turns any codebase into an interactive knowledge graph. The core logic lives in understand-anything-plugin/packages/core/src/ — a multi-agent pipeline that scans your project, extracts every file, function, class, and dependency, then builds a searchable graph you can explore in a browser dashboard. The analyzer/ directory contains the graph builder (graph-builder.ts), LLM-based analysis (llm-analyzer.ts), and tour generator (tour-generator.ts). Language support spans 40+ configs under languages/configs/, from Python and TypeScript to Dockerfiles and Terraform.

The dashboard is an Astro-based homepage (homepage/) with interactive visualization. The plugin integrates with Claude Code, Codex, Cursor, Copilot, and Gemini CLI via platform-specific configs in .claude-plugin/, .copilot-plugin/, and .cursor-plugin/.

Real-World Use

A developer joins a team maintaining a 150,000-line Rails monolith. Instead of reading files sequentially, they run the project scanner, then open the dashboard. The graph shows domain boundaries, data flow between services, and entry points. Clicking a controller node reveals its dependencies, tests, and a plain-English summary. The tour generator creates a guided walkthrough of the payment flow. What would take days of manual reading takes an hour.

The Bottom Line

Understand Anything solves a real onboarding and code comprehension problem with a practical, well-architected approach. The multi-agent pipeline and 40+ language configs make it immediately useful for most teams. Best suited for medium-to-large projects where manual code reading is a bottleneck. Solo developers on small codebases will find less value.
