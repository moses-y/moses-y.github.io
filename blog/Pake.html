The Problem

Building a desktop app wrapper around a website traditionally means Electron: heavy installers (100MB+), high memory usage, and complex build tooling. Developers who want a lightweight, single-purpose web-to-desktop conversion have few good options.

What This Does

Pake wraps any webpage as a native desktop app using Tauri (Rust) instead of Electron. The core logic lives in src-tauri/src/lib.rs and src-tauri/src/main.rs, which handle window management, menu creation (src-tauri/src/app/menu.rs), and JavaScript injection (src-tauri/src/inject/). The CLI entry point at bin/cli.ts orchestrates platform-specific builders (bin/builders/MacBuilder.ts, WinBuilder.ts, LinuxBuilder.ts) that compile the Tauri project with user-provided URL, icon, and window options.

Output binaries are roughly 5MB—about 20x smaller than equivalent Electron apps. The project ships with pre-built packages for 15+ popular sites (Twitter, WeRead, DeepSeek) and a GitHub Actions workflow (single-app.yaml) for online building without local setup.

Code Health & Issues

Med - bin/utils/shell.ts executes shell commands without strict input sanitization. User-supplied app names or URLs could introduce command injection if passed unsanitized to cargo tauri build. Low - src-tauri/pake.json and src-tauri/rust_proxy.toml are configuration files committed to the repo containing environment-specific paths and proxy settings. These should be documented or externalized. Low - Tests exist (13 files) but coverage is uneven. tests/unit/ has unit tests for builders and CLI options, but tests/integration/ has only one file testing workflow paths. No tests exercise the actual Tauri build pipeline. Clean otherwise - CI is configured (quality checks, npm publish, release), lockfiles are present (pnpm-lock.yaml, Cargo.lock), and a LICENSE file is included.

The Bottom Line

Pake is a practical tool for generating lightweight desktop wrappers around web apps. It solves a real problem—Electron bloat—with a solid Tauri foundation and a clean CLI. The command injection risk in the shell utility is worth patching before production use, but for internal tools and personal projects, this is a well-built, low-friction solution.
