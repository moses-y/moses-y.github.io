Forked from MaxMiksa/Auto-Company

The Problem The Auto-Company repository aims to address the challenge of creating a fully autonomous AI company that can operate 24/7 without human intervention. This problem requires a sophisticated system that can ideate products, make decisions, write code, deploy, and market, all while minimizing the need for human oversight.

What This Does The Auto-Company repository utilizes a unique architecture that leverages Agentic Workflows to orchestrate 14 autonomous AI agents. Each agent is modeled after world-class experts in their domain and works together to execute tasks. The system uses a combination of Codex CLI and Claude Code to enable the AI team to read shared consensus memory, decide on actions, form squads, execute tasks, and update consensus memory. The PROMPT.md and consensus.md files play a crucial role in this process, serving as the primary sources of information for the AI team.

The repository's structure, with folders like .claude/skills and dashboard, suggests a modular approach to organizing the various components of the system. The presence of files like requirements.txt and Makefile indicates that the project uses a combination of Python and other tools to manage dependencies and automate tasks.

Real-World Use A practical scenario for using the Auto-Company repository could involve setting up a fully autonomous AI-powered startup. By leveraging the repository's architecture and tools, entrepreneurs could create a company that can operate independently, making decisions and executing tasks without the need for human intervention. For example, the deep-research skill could be used to identify market trends and opportunities, while the devops skill could be used to deploy and manage the company's infrastructure.
