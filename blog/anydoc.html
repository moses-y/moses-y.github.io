anydoc

Convert Word, PowerPoint, Excel, OpenDocument, RTF, EPUB, CSV, and PDF to clean Markdown. Built in Rust, with Node.js and Python bindings.

Forked from firecrawl/anydoc

The Problem Converting documents from various formats to clean Markdown can be a challenging and time-consuming task. Different formats have different structures and requirements, making it difficult to achieve consistent results.

What This Does The anydoc repository provides a solution to this problem by offering a fast Rust library that converts documents from various formats (Word, PowerPoint, Excel, OpenDocument, RTF, EPUB, CSV, and PDF) to clean GitHub-Flavored Markdown. The library includes bindings for Node.js and Python, making it accessible to a wide range of developers. The anydoc library uses a shared document model to parse and render documents, ensuring consistent output across different formats. For example, the to_markdown function in node/README.md and python/README.md demonstrates how to convert a document to Markdown using the library.

Real-World Use A practical scenario for using anydoc is in a document processing pipeline, where documents from various sources need to be converted to a standard format for further processing or analysis. For instance, a developer can use the anydoc CLI to convert a batch of documents to Markdown, and then use the resulting Markdown files as input for a machine learning model. The anydoc library can be integrated into a workflow using the npx @firecrawl/anydoc command or by installing it globally with npm install -g @firecrawl/anydoc.
