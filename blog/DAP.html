The Problem

Panoramic depth estimation remains a specialized niche compared to standard perspective depth models. This repository addresses the gap for 360° content, providing a foundation model capable of estimating depth across panoramic imagery, which is critical for immersive XR applications and 360° video processing.

What This Does

The implementation is structured around a depthanythingv2_metric core, utilizing Vision Transformers (Dinov2/Dinov3) and a DPT head for depth prediction. The datasets/ directory (75 files) handles data loading for panoramic-specific datasets like insta23k and M3D, alongside standard vision datasets. Configuration is managed via config/infer.yaml and config/test.yaml, which dictate model paths and inference parameters.

How To Use It

Setup

Clone the repository and install dependencies as specified in the README. The install requires PyTorch v2.7.1 and torchvision v0.22.1.

git clone https://github.com/Insta360-Research-Team/DAP cd DAP

conda create -n dap python=3.12 conda activate dap

pip install torch==2.7.1 torchvision==0.22.1 pip install -r requirements.txt

Configuration

Required configuration files are located in the config/ directory. config/infer.yaml and config/test.yaml must be present or adjusted for specific model checkpoints and input resolutions prior to running scripts.

Running it

Inference is invoked via the test script:

python test/infer.py

Evaluation follows the same pattern:

python test/eval.py
