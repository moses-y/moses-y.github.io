IKEA 3D Model Download Button

Adds ability to download models from IKEA website

The Problem

IKEA's website displays 3D product views but offers no way to save the underlying .glb model files. Anyone planning a room layout in Blender or other 3D software must either manually extract the model from browser network traffic or skip the workflow entirely. This script automates that extraction.

What This Does

ikea-3d-model-downloader.user.js is a Tampermonkey userscript that injects a "Download 3D" button next to IKEA's existing "View in 3D" button on product pages. When clicked, it fetches the .glb file from IKEA's backend and saves it locally with a filename derived from the product name and color.

The script handles multiple IKEA language versions and includes a keyboard shortcut (Ctrl + Alt + D) as a fallback when the button doesn't render. The repo also contains README.md with installation and troubleshooting instructions, and sample.jpg showing the button in action. This is a fork of a popular upstream project (1,416 stars), with a bugfix dated January 2026.

How To Use It

Setup: Install the Tampermonkey browser extension. Install the script from the raw GitHub link in the README, or create a new script in Tampermonkey and paste the contents of ikea-3d-model-downloader.user.js. If using Chrome, Edge, or Opera, enable developer mode in browser settings.

Configuration: No configuration required. The script has no user-editable settings or environment variables.

Running it: Navigate to any IKEA product page with a "View in 3D" button. Click the new "Download 3D" button, or press Ctrl + Alt + D.

Real-World Use

A user planning a home office opens an IKEA product page for a desk, clicks "Download 3D," and gets BEKANT - Black-brown.glb. They import that file into Blender alongside models from other manufacturers, verify dimensions and sightlines, and finalize the layout before purchasing. The script removes the manual network-inspection step that would otherwise be required.
