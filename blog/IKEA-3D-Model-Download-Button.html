The Problem IKEA product pages display interactive 3D models via a "View in 3D" viewer, but lack a native mechanism to download the underlying GLB file. This forces users to rely on third-party workarounds or lose the model entirely when planning home layouts.

What This Does The repository contains three files at root: README.md, ikea-3d-model-downloader.user.js, and sample.jpg. The core functionality lives in ikea-3d-model-downloader.user.js, a Tampermonkey userscript that injects a "Download 3D" button alongside IKEA's existing "View in 3D" button on product pages. The script auto-extracts the GLB URL, names the file [Product Name] - [Color].glb, and works across localized IKEA domains. As the README notes, the script was updated 30.01.2026 with a bugfix, indicating active maintenance for the fork.

How To Use It Setup: Install the Tampermonkey browser extension. Then either click the raw install link referenced in README (ikea-3d-model-downloader.user.js) or create a new Tampermonkey script and paste the userscript contents into it. The README specifies that Chromium-based browsers (Chrome, Edge, Opera) require developer mode enabled in browser settings for the script to inject properly. Configuration: No environment variables, keys, or config files are defined. The script operates entirely against the page DOM of IKEA product pages. The only "configuration" is the browser-level developer mode flag noted for Chrome/Edge/Opera. Running it: Navigate to any IKEA product page that includes a "View in 3D" button. The "Download 3D" button appears adjacent to it. Click to download the .glb file, saved with the format [Product Name] - [Color].glb. If the button doesn't appear, the README suggests refreshing, pressing Ctrl + Alt + D, or verifying the page has a 3D model available.

Real-World Use A home designer browsing an IKEA product page (e.g., a KALLAX unit or LISABO lamp with 3D configurability) can click "Download 3D" and immediately obtain a .glb file. This file can be imported into Blender, SketchUp, or any home planning software to visualize scale, material, and placement before purchase. Example workflow: open https://www.ikea.com/us/en/p/kallax-shelf-unit-001/, ensure the "View in 3D" badge is present, click the newly injected "Download 3D" button, and open the saved KALLAX - white.glb in Blender for a quick scene layout test.
