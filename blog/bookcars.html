The Problem

Operating a car rental business requires managing fleets, bookings, payments, and multiple suppliers across web and mobile channels. Most off-the-shelf solutions lock you into a single payment provider, lack multi-supplier support, or don't offer a mobile app. Building this from scratch takes months.

What This Does

BookCars is a full-stack car rental platform with an admin panel (admin/), a web frontend, and a mobile app. The admin panel manages suppliers, cars, countries, locations, parking spots, customers, bookings, and payments. It supports both single-supplier and multi-supplier modes, with each supplier getting a dedicated admin panel after email-based account creation.

The platform ships with Stripe and PayPal payment gateways built in, configurable via environment variables (admin/.env.example). The admin panel is a React TypeScript app with 74 TSX component files and 74 CSS files. CI/CD runs through GitHub Actions (build, test, containerize, release workflows in .github/workflows/). Docker deployment is supported with separate production and development Dockerfiles (admin/Dockerfile, admin/Dockerfile.dev).

Real-World Use

A regional car rental company with 15 independent suppliers deploys BookCars via Docker on a single VPS. Customers browse available cars through the mobile app, filter by pickup/drop-off location and time, and complete checkout with PayPal. Each supplier logs into their admin panel to manage their fleet and view bookings. The central admin monitors all suppliers, handles payments, and adjusts commission rates from the settings page.

The Bottom Line

This is a well-structured admin panel for a car rental platform, but it's only one piece of a larger system. The actual value depends on having access to the backend, frontend, and mobile app from the original repository. Use this if you need a production-ready rental admin interface with multi-supplier support and dual payment gateways, but be prepared to integrate the missing backend services yourself.
