pindrop

A native macOS menu bar dictation app using local speech-to-text with WhisperKit

Forked from watzon/pindrop

The Problem Mac users who need reliable, offline dictation must either rely on Apple’s built‑in Speech Recognition (limited language support) or use third‑party cloud services that expose audio to external servers. Both options compromise privacy or lack flexibility for developers who want to embed transcription in custom macOS workflows.

What This Does Pindrop is a native macOS menu‑bar app that captures microphone audio and runs it through local Whisper models via WhisperKit (see Pindrel/AppCoordinator.swift for the transcription flow). The app can also fall back to cloud providers (OpenAI, Anthropic, OpenRouter) whose API keys are stored in the macOS Keychain.

Key components:

Pindrop/AppCoordinator.swift – orchestrates UI, hot‑key handling, and starts the selected transcription engine. Pindrop/AppLocalization.swift – loads the 31‑language YAML files under Localization/app/.yml and supplies localized strings to SwiftUI views. Pindrop/AppTestMode.swift – toggles a mock transcription pipeline used by the test suite (PindropTests/).

The Xcode project (Pindrop.xcodeproj/) uses SwiftPM to fetch WhisperKit, FluidAudio, and Sparkle for auto‑updates. CI is defined in .github/workflows/ci.yml, which runs xcodebuild test on macOS runners.

How To Use It

Setup Clone the repo and open Pindrop.xcodeproj in Xcode 15+. Resolve Swift packages (File → Packages → Resolve Package Versions). Build the Pindrop scheme:

xcodebuild -scheme Pindrop -configuration Release clean build

Configuration Local model selection is persisted in UserDefaults via AppCoordinator. Optional cloud keys are entered through the app’s Settings UI; they are saved in the Keychain (no source‑code files expose them). Localization files are edited directly in Localization/app/.yml; the app reloads them at launch.

Running Launch the built app (DerivedData/.../Build/Products/Release/Pindrop.app). The menu‑bar icon opens a pop‑over where you can:

Choose a transcription engine (WhisperKit, Parakeet, SenseVoice, Apple Speech). Press the global hot‑key (default ⌘⇧D) to start push‑to‑talk. View live transcription and export via the UI buttons (JSON, CSV, plain text).

For developers, the test target can be executed with:

xcodebuild test -scheme Pindrop -destination 'platform=macOS,arch=arm64'

Real‑World Use A content‑creation team can install Pindrop on each Mac, enable the “copy to clipboard” option, and dictate meeting notes directly into any document. Because transcription runs locally, no audio leaves the machine, satisfying GDPR‑style privacy requirements while still providing speaker diarization and multi‑language support.

Code Health & Issues

Low – Missing high‑level README – the repository lacks a top‑level README.md that explains build prerequisites, required macOS version, or contribution workflow. Medium – Limited test coverage – only four test files are present; they focus on UI scaffolding and do not exercise the transcription pipelines or error‑handling paths. Low – Hard‑coded hot‑key strings – hot‑key definitions live in AppCoordinator.swift without a user‑configurable fallback, making customization difficult. Low – No automated linting – CI runs xcodebuild test but does not invoke SwiftLint or similar static analysis, so style inconsistencies may go unnoticed. Low – Asset bloat – the Assets.xcassets folder contains >150 SVG icons; while harmless, it inflates the repo size and may slow CI checkout.

No obvious security red flags: API keys are never committed, and the app uses the Keychain for storage. The CI pipeline is functional, and the Xcode project builds without errors on macOS 14+.

The Bottom Line Pindrop delivers a fully offline, macOS‑native dictation experience with a solid SwiftUI codebase and optional cloud fallback. It is ready for power users who need privacy‑preserving transcription, but the project would benefit from a comprehensive README, broader test coverage, and configurable hot‑keys before being adopted in a larger enterprise setting.
