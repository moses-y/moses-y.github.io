What This Does: The repo is structured around Python-driven font generation and feature compilation. pyproject.toml and requirements.txt define the build pipeline, while Dockerfile enables containerized builds. Generated WOFF2 variants appear in woff2/var/.

Customize features: modify config.json or enable/disable feature flags in source/features/README.md; feature definitions reside in source/features/.fea and source/py/feature/.
