The Problem

Teams learning Kubernetes face a common wall: tutorials teach isolated concepts, but production use requires wiring together pods, services, RBAC, network policies, and CI/CD. This repo addresses that gap by pairing concept walkthroughs with deployable YAML and real-world project patterns, so learners see both the "what" and the "how" of Kubernetes.

What This Does

The repo is a structured learning path, not a library or framework. The learning/ directory holds 12 topic folders, each pairing a README.md with working manifests. learning/What-is-Pod-in-Kubernetes/ covers pod basics with pod.yaml, deployment.yaml, and probe examples for liveness and readiness. learning/RBAC-Access-Control/ provides a role.yaml to demonstrate authorization.

The projects/ directory contains three multi-stage scenarios. 10-microservices-deployment-eks/ includes an EKS deployment with a Jenkinsfile and service accounts, roles, and security context YAMLs. Uber-Clone-DevSecOps/ pairs a jenkinsfile with a README covering security-focused CI/CD. The CKAD-exercises/ folder holds 10 markdown files of exam-style drills, from core concepts to Helm and CRDs.

How To Use It

The repo has no build system, package manager, or install script. Everything is YAML and Markdown, meant to be read and applied directly.

Setup: Install kubectl and a local cluster (Minikube, kind, or k3s). The root README links to a setup gist for CLI and cluster configuration.

Configuration: No environment variables or config files are required. Each topic's YAML is self-contained. For example, learning/Managing-ConfigMaps-and-Secrets/configmap-literal.yaml defines a ConfigMap, and pod-with-config.yaml consumes it.

Running it: Apply manifests directly with kubectl. Referenced files are complete, not fragments:

kubectl apply -f learning/What-is-Pod-in-Kubernetes/pod.yaml kubectl apply -f learning/Deploying-an-Application-on-Kubernetes/deployment.yaml kubectl apply -f learning/Deploying-an-Application-on-Kubernetes/service.yaml

For the EKS project, apply the security, service account, role, and binding manifests in order, then run the Jenkins pipeline defined in Jenkinsfile.

Real-World Use

A developer preparing for the CKAD exam can work through CKAD-exercises/ as drills. A team standing up a microservices stack on AWS can use projects/10-microservices-deployment-eks/ as a reference for RBAC setup and CI/CD wiring. A platform engineer can adapt the network policy patterns from learning/Network-Policies-in-K8s/ to lock down a production cluster.

The Bottom Line

This is a solid study companion for Kubernetes fundamentals and CKAD prep, with accurate, hand-written manifests and good coverage of core topics. It is not a production codebase—no tests, no license, and no CI—so treat it as a reference for learning, not something to vendor directly. Best suited to individuals or teams working through Kubernetes certification or early adoption.
