The Problem

Teams building or researching on‑policy distillation (OPD) for large language models need a single, up‑to‑date source that aggregates papers, reports, and open‑source implementations. Scattered references waste time and increase the risk of missing recent industrial recipes.

What This Does

The repository is an awesome‑list style catalog of OPD resources. The core content lives in README.md, which organizes 492 entries into logical sections (surveys, core papers, taxonomy, frameworks, etc.). Supporting files provide meta‑information (CITATION.cff), contribution guidelines (CONTRIBUTING.md), and licensing (LICENSE). A single utility markdown file under .claude/skills/add-paper/SKILL.md documents a Claude‑specific skill for adding new entries, but it does not affect the list itself.

Real‑World Use

A research team designing an OPD pipeline can clone the repo, locate the latest “Frameworks and Implementations” entries (e.g., open‑source codebases from Alibaba or Nvidia), and directly import those libraries into their experiment scripts. A typical workflow:

git clone https://github.com/yourorg/awesome-on-policy-distillation.git cd awesome-on-policy-distillation Find a framework, e.g., "Qwen3 OPD Toolkit" Follow its upstream installation instructions

The list also serves as a checklist for literature reviews, ensuring that a project cites both foundational papers (MiniLLM, GKD) and recent industrial reports.

The Bottom Line

awesome-on-policy-distillation delivers a well‑organized, community‑curated index of OPD literature and tooling, useful for researchers and engineers needing a quick reference point. It requires no installation or runtime steps, but the lack of automated validation means contributors must be diligent when updating entries. Ideal for teams that want a vetted bibliography and a starting point for selecting open‑source OPD frameworks.
