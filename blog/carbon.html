Abstract

Carbon is an open source ERP, MES and QMS for manufacturing. Perfect for complex assembly, contract manufacturing, high volume, and configure to order manufacturing.

Forked from crbnos/carbon

Technical Briefing: Carbon Manufacturing ERP/MES/QMS

The Problem

Manufacturers face fragmented tooling with limited modern API integration, vendor lock-in, and inflexible ERP/MES solutions that don't adapt to unique workflows. Carbon addresses these gaps with an open-core system combining ERP, MES, and QMS capabilities in a single extensible platform.

What This Does

Carbon provides a full-stack manufacturing platform with:

  1. ERP Core (apps/erp/): - Sales, purchasing, inventory, accounting (GL) - Material requirements planning (MRP) - Traceability (lot/serial tracking) - Nested bills of material (BoM)
  1. MES Capabilities (apps/assembler/): - Shop floor execution - Job operations tracking - Assembly planning (Rust-based apps/assembler/src/main.rs)
  1. QMS Features (packages/quality/): - Inspections - Non-conformance tracking - CAPA management

The system is built on a monorepo structure with:

  • TypeScript/React frontend (apps/academy/, apps/erp/)
  • Rust backend components (apps/assembler/, crates/)
  • Supabase database integration
  • Docker containerization

How It Is Wired

The system follows a clean architectural separation:

  • API Entry Points:
  • ERP: apps/erp/package.json exports API handlers
  • Assembly: apps/assembler/src/main.rs provides Rust-based services
  • Data Flow: 1. Frontend components (apps/erp/app/components/) make API calls 2. Requests route through Supabase RLS policies for authorization 3. Core business logic executes in Rust services 4. Database operations handled via Supabase migrations (packages/database/)

Critical dependencies:

  • packages/database/ manages all schema migrations
  • packages/core/ contains shared business logic
  • crates/geometry/ handles spatial calculations for assembly operations

How To Use It

Setup:

git clone https://github.com/moses-y/carbon
cd carbon
pnpm install
docker-compose up -d

Configuration:

  • Environment variables in .env (see .env.example)
  • Database configuration in packages/database/

Running:

  1. Start services: pnpm run dev
  2. Access ERP at http://localhost:3000
  3. Assembly services run via apps/assembler/ Rust component

Real-World Use

A typical workflow might involve:

  1. Creating a new product configuration via the configurator
  2. Generating a BoM in the ERP system
  3. Scheduling assembly jobs through the MES interface
  4. Executing quality inspections via QMS tools
  5. Tracking inventory movements with full traceability
