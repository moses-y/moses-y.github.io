tabularis

Open-source database client for PostgreSQL, MySQL/MariaDB and SQLite with SQL notebooks, visual EXPLAIN, AI and MCP built in. Hackable with plugins.

Forked from TabularisDB/tabularis

The Problem

Database tools typically force a trade-off: simple clients lack analytical depth, while full IDEs are heavy and don't support notebook-style workflows. Teams who need to explore databases interactively, document queries alongside results, and integrate AI assistance often end up juggling multiple tools.

What This Does

Tabularis is a desktop database client built with Tauri (Rust backend, React frontend) that supports PostgreSQL, MySQL/MariaDB, and SQLite. Its core differentiator is SQL notebooks—documents combining SQL cells, Markdown, and charts with cross-cell variable passing. The demo/ directory shows sample notebooks and database init scripts for all supported engines.

The plugin system, defined in packages/plugin-api/ and scaffolded via packages/create-plugin/, lets you extend the client in any language using JSON-RPC over stdio. Templates in packages/create-plugin/templates/ cover both Rust drivers and UI extensions. The project also ships a built-in MCP server for AI agent integration and a visual EXPLAIN tool.

Real-World Use

A data analyst connects to a Postgres analytics database using demo/init/postgres/02-analytics-demo.sql. They run parameterized queries in a notebook, share results as a .tabularis-notebook file, and use the visual EXPLAIN to optimize a slow JOIN. The MCP server lets an AI agent query the database directly from a chat interface.

Code Health & Issues

The codebase appears well-structured with CI (ci.yml), release automation (release.yml), and package distribution workflows for AUR, Snap, and WinGet. Tests exist in packages/create-plugin/tests/, and the project uses ESLint, TypeScript strict mode, and Rust toolchain configuration. No obvious security red flags like hardcoded credentials.

Med - Plugin API types are defined in packages/plugin-api/src/types.ts but the validation logic in packages/create-plugin/src/validate.ts covers only plugin metadata, not runtime input sanitization for plugin-host communication. This could allow malformed JSON-RPC messages.

Low - The .claude/ and .agents/ directories contain AI agent skill definitions that duplicate content (e.g., identical SKILL.md files in both folders). This suggests incomplete cleanup rather than a functional issue.

Low - No end-to-end tests for the Tauri desktop application itself. The five test files cover only the plugin scaffolding CLI.

The Bottom Line

Tabularis is a well-architected database client that genuinely differentiates with notebook support and a language-agnostic plugin system. It's production-ready for individual developers and small teams who need an open-source alternative to TablePlus or DBeaver with better analytical workflow support. The plugin ecosystem is still young, and enterprise features like SSO or audit logging are absent.
