purple

Open-source terminal SSH manager that keeps ~/.ssh/config in sync with your cloud infra across 16 cloud providers. Spin up a VM, it shows up. Destroy it, it dims. Plus live tunnel monitoring, fleet-wide Docker and Podman, scp, Vault SSH certs and an MCP server for AI agents. Rust TUI, MIT.

Forked from erickochen/purple

The Problem Managing SSH connections to multiple cloud providers can be cumbersome, with manual configuration and updates required for each new instance or change in infrastructure. This can lead to errors, inconsistencies, and wasted time.

What This Does The purple repository provides an open-source terminal SSH manager that keeps ~/.ssh/config in sync with cloud infrastructure across 16 providers. It features a fast Rust TUI with fuzzy search, file transfer, Docker and Podman over SSH, and multi-host SSH key push. The src/lib.rs and src/main.rs files serve as the entry points for the application, with configuration handled by Cargo.toml. The project utilizes GitHub Actions for CI/CD and has a well-structured directory layout, including separate folders for source code, tests, and documentation.

Real-World Use For example, when spinning up a new VM on AWS, the purple tool can automatically add the instance to the ~/.ssh/config file, eliminating the need for manual updates. The fuzz folder contains test cases for the SSH configuration parser, ensuring that the tool can handle various input formats and edge cases.

Code Health & Issues Low - Missing input validation for some user-provided data - src/app/forms.rs Med - Potential for race conditions when updating ~/.ssh/config concurrently - src/handler/eventloop/providersync.rs Low - Some dependencies are not pinned to specific versions, which could lead to compatibility issues - Cargo.toml

However, the repository appears to be well-maintained, with a comprehensive test suite (15 test files found) and a clear CI/CD pipeline configured. The presence of a LICENSE file, README.md, and SECURITY.md also indicates a focus on code health and security.

The Bottom Line The purple repository provides a valuable tool for managing SSH connections to cloud infrastructure, with a well-structured codebase and a focus on usability and security. While some minor issues were identified, the project appears to be well-maintained and suitable for use in production environments, particularly for teams or individuals managing multiple cloud providers.
