The Problem

Clients need ready‑to‑run solutions for a set of public data‑science and big‑data questions posted on TestDome. The repository delivers code snippets, visualisations, and explanatory notes that can be copied into a local environment for quick validation or learning.

What This Does

The repo groups solutions by topic: Python (6 scripts), R (3 scripts), and visual assets for PowerBI, Tableau, and Spark.

  • Python-for-Data-Science/iris_classifier.py trains a K‑NN model on the Iris data set.
  • Python-for-Data-Science/marketing_costs.py calculates cost‑per‑click and ROI from a CSV.
  • R/login_table.R generates a login table for a marketing campaign.

Each script is self‑contained; no shared libraries or database connections are referenced.

How It Is Wired

There is no single executable or import graph. The entry point for each solution is the script file itself.

  • Running python Python-for-Data-Science/iris_classifier.py imports sklearn and pandas, loads the data from a local CSV, trains the model, and prints accuracy.
  • R/login_table.R loads tidyverse, reads login_data.csv, and outputs a summary table.
  • The test files (tests/test_*.py) import the same modules and assert basic invariants, but they are not wired into a CI pipeline.

Because the scripts are independent, changing one does not affect the others; there are no shared configuration files or external services.

How To Use It

# Clone the repository
git clone https://github.com/moses-y/testdome-data-science-questions

# Navigate to a language folder and run the desired script
cd Python-for-Data-Science
python iris_classifier.py

No virtual environment or dependency file is supplied; install the required packages manually (pip install pandas scikit-learn). No environment variables are required.

Real‑World Use

A data‑science trainer can copy Python-for-Data-Science/marketing_costs.py into a Jupyter notebook, feed it a real campaign CSV, and immediately obtain cost‑analysis metrics for a lesson.
