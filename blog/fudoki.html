An interactive Japanese text analysis and speech synthesis web app

Forked from iamcheyan/fudoki

The Problem The Fudoki repository aims to address the need for an interactive Japanese text analysis and speech synthesis web app. This tool is designed to help users visualize Japanese text structures, providing features such as text segmentation, part-of-speech tags, and readings, as well as text-to-speech functionality.

What This Does The Fudoki web app utilizes the static/js/dictionary.js and static/js/tts.js files to provide dictionary and text-to-speech functionality, respectively. The static/libs/kuromoji.js library is used for Japanese text segmentation and analysis. The app also features a built-in Markdown editor, EasyMDE, which allows users to format their text while maintaining compatibility with Japanese analysis features.

Real-World Use A practical scenario for using Fudoki would be for language learners or educators who need to analyze and visualize Japanese text structures. For example, a user could input a Japanese sentence into the app, and Fudoki would segment the text, provide part-of-speech tags and readings, and read the text aloud via the Web Speech API.
