agent flow

Real-time visualization of Claude Code agent orchestration — see your agents think, branch, and coordinate as they work.

Forked from patoles/agent-flow

The Problem

Claude Code and Codex execute agentic workflows as black boxes. You see inputs and final outputs, but the intermediate reasoning, tool call chains, and subagent coordination remain invisible. Debugging failures means guessing at what happened inside the agent loop.

What This Does

Agent Flow captures real-time events from Claude Code and Codex sessions and renders them as an interactive node graph on an HTML canvas. The extension/src/ directory contains watchers for both runtimes: session-watcher.ts monitors Claude Code's project files, while codex-session-watcher.ts tails Codex's JSONL rollout files. Events flow through a relay server (scripts/relay.ts) to the web frontend.

The web UI in web/components/agent-visualizer/ renders agents as nodes with animated tool calls, edges for branching/return flows, and panels for timelines, transcripts, and file attention heatmaps. The canvas renderer (canvas/draw-agents.ts, canvas/draw-edges.ts) handles pan/zoom and hit detection for clicking into details.

Real-World Use

Run npx agent-flow-app in one terminal, start a Claude Code session in another. Watch agents spawn subagents, make tool calls (edit files, run commands), and return results—all visualized in real time. When a build fails, trace the exact tool call sequence that led there instead of re-running with verbose logging.

The Bottom Line

Agent Flow solves a real debugging pain point for anyone building multi-step agent workflows with Claude Code or Codex. The architecture is clean—separate watchers, a relay server, and a canvas-based UI—and it works out of the box with npx agent-flow-app. It's most valuable for teams shipping agent-heavy features who need observability into agent behavior. Missing CI and sparse test coverage are the main risks for production adoption.
