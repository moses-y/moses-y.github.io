The Problem

Developers using the Pi editor need a quick way to capture spoken notes without leaving the editor or relying on cloud services. Existing solutions require manual copy‑paste or external apps, breaking the workflow and raising privacy concerns.

What This Does

pi-transcribe adds a local speech‑to‑text capability directly inside Pi. The extension registers a terminal shortcut (default Ctrl+Alt+Z) that toggles recording, shows a live level meter, and inserts the transcription at the cursor when finished. Core logic lives in src/transcription.ts, which streams audio to the selected model (see src/models.ts and src/model-picker.ts). UI elements such as the level meter and settings menu are implemented in src/visualizer.ts, src/settings-menu.ts, and src/onboarding.ts. The generated catalog (src/catalog.generated.ts) and its source (catalog/catalog.json) expose the available models and language packs.

How To Use It

Setup

Clone the repo git clone https://github.com/earendil-works/pi-transcribe.git cd pi-transcribe

Install dependencies (npm scripts are disabled by default)

npm install --ignore-scripts

The README also documents an alternative Pi‑specific install: pi install ssh://git@github.com/earendil-works/pi-transcribe or, after an npm release pi install npm:@earendil-works/pi-transcribe

Configuration

Settings are edited through the Pi command /transcribe. Internally they are persisted in src/settings.ts and src/settings-menu.ts. No external environment variables or secret files are required.

Running

From a checkout, start Pi with the extension loaded: pi -e /absolute/path/to/pi-transcribe

Press Ctrl+Alt+Z (or the user‑defined shortcut) while Pi has focus to begin recording; press again to stop and insert the transcribed text. Esc aborts the session.

Real‑World Use

A developer writing documentation can dictate a paragraph without leaving the editor:

In Pi editor

Ctrl+Alt+Z # start recording [Speak] "The new API endpoint returns a JSON payload with user metrics." Ctrl+Alt+Z # stop The text appears at the cursor instantly.

The feature is especially useful in environments with strict data residency, as all processing occurs locally.

Code Health & Issues

Med – No test suite – No .test. files; core functions (transcribeAudio, model loading) are untested. Med – No CI/CD – Repository lacks .github/workflows or other pipeline definitions, so builds and linting are manual. Low – Limited error handling – src/audio.ts and src/transcription.ts assume microphone availability; failures are logged but not surfaced to the user. Low – Hard‑coded shortcut – Default keybinding is defined in src/shortcuts.ts; changing it requires editing source or using the /transcribe command. Info – License present – LICENSE file is included, providing clear legal terms. Info – TypeScript strictness – tsconfig.json enables strict type checking, reducing certain class of bugs.

The Bottom Line

pi-transcribe delivers a functional, locally‑run dictation extension for Pi with minimal setup and clear integration points. The codebase is small and type‑safe but lacks automated testing and CI, which raises maintenance risk for production use. Suitable for solo developers or teams that can accept manual validation and are comfortable extending the code to add tests or CI pipelines.
