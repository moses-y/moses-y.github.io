Ever® Gauzy™ - Open Business Management Platform (ERP/CRM/HRM/ATS/PM) - https://gauzy.co

Forked from ever-co/ever-gauzy

The Problem

Businesses managing teams, clients, projects, and finances often juggle multiple tools (ERP, CRM, HRM, time tracking) that don't integrate. This creates data silos, duplicate entry, and no unified view of operations or employee productivity.

What This Does

Ever Gauzy is an open-source platform that combines ERP, CRM, HRM, ATS, and project management into one system. It includes employee time tracking with activity monitoring, financial management (invoicing, accounting, payments), sales pipelines, inventory management, and reporting. The platform exposes headless APIs documented at api.gauzy.co/docs.

The repository is primarily infrastructure and configuration—98 YAML files define CI/CD pipelines (./.github/workflows/), Docker deployments (./.deploy/), and Kubernetes manifests (./.deploy/k8s/). The actual application code (TypeScript, Angular) is minimal here; this appears to be the deployment/infrastructure layer for the main ever-co/ever-gauzy monorepo (4,241 stars), which contains the application source.

Real-World Use

A consulting firm with 50 employees deploys Gauzy via Docker Compose (./.deploy/ssh/with-letsencrypt/demo/). They manage client projects, track billable hours with the desktop timer, generate invoices, and run payroll—all from one platform. The .env.compose file configures database and API connections for the deployment.

The Bottom Line

Ever Gauzy is a legitimate, full-featured open-source business management platform with strong deployment infrastructure (Docker, Kubernetes, multiple cloud providers). The repository itself is the infrastructure layer—the actual application code lives in the parent monorepo. Best suited for organizations that need an integrated ERP/HRM/time-tracking system and have the DevOps capability to manage the deployment complexity. Not appropriate for simple needs or teams without infrastructure experience.
