EVA

EVA is an AI-assisted penetration testing agent that enhances offensive security workflows by providing structured attack guidance, contextual analysis, and multi-backend AI integration.

Forked from ARCANGEL0/EVA

The Problem

Penetration testing generates large volumes of raw command output that must be interpreted and acted upon quickly. Analysts often lose context across sessions, miss vulnerability indicators buried in enumeration results, or spend excessive time reformatting findings into reports. EVA addresses this by wrapping an LLM around the pentest workflow, providing structured attack guidance and automated analysis of command output as the engagement progresses.

What This Does

EVA is a Python-based CLI agent that orchestrates penetration testing engagements through an interactive shell. The core entry point is eva.py, which coordinates the pentest lifecycle across modules/workflow.py (phase orchestration), modules/attackmap.py (attack path generation), and modules/exploitsearch.py (exploit lookup). Session state persists via sessions/evasession.py, allowing engagements to be paused and resumed.

The system supports multiple AI backends through modules/llm.py: local Ollama, OpenAI, Anthropic, Gemini, G4F.dev, and custom API endpoints. modules/promptbuilder.py constructs context-aware prompts from target information and prior command output, while modules/tooling.py handles command execution and result capture. modules/reporting.py generates engagement reports, and utils/configloader.py manages backend selection and API credentials.

Real-World Use

A consultant running an external pentest against a client web application could use EVA to structure the engagement. After defining the target, EVA's workflow engine moves through reconnaissance, enumeration, and exploitation phases. The AI backend analyzes nmap or gobuster output and suggests next steps, while the session persists progress between work sessions. The reporting module generates a structured findings document for the final deliverable.

The Bottom Line

EVA is a functional prototype that demonstrates a sensible architecture for AI-guided pentesting, with good modular separation and multi-backend support. It is not production-ready: no tests, no CI, no license, and no setup documentation. Security teams comfortable with Python and willing to add their own testing and configuration layers could find it useful; others should wait for maturity.
