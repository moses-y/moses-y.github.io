investing algorithm framework

Framework for developing, backtesting, and deploying automated trading algorithms and trading bots.

Forked from coding-kitties/investing-algorithm-framework

The Problem Most quant tool‑kits stop after a single backtest number, leaving the user to manually hunt through results, charts, and reports to decide which strategy actually performs best. This repo attempts to close that gap by bundling strategy creation, backtesting, comparison, and deployment into one package.

What This Does The framework is built around a full loop: create → backtest → compare → deploy. A self‑contained HTML dashboard is generated that lets you rank, filter, and visually compare every tested strategy—no notebooks required. The docs live under docusaurus/ (125 files) and include guides on getting started, data sources, and advanced concepts such as optimization and parallel processing. Example algorithms are stored in examples/batchone/<hash>/; each folder contains algorithmid.json, parameters.json, and backtest run directories with metrics.json and run.json, illustrating how strategies are persisted and compared. A LICENSE file declares Apache 2.0, and the repo ships with GitHub Actions workflows (test.yml, deploy-docs.yml, publish.yml) and 54 test files, indicating a baseline CI/CD setup.

How To Use It

Setup The Docs site is a Docusaurus project. From the repo root, cd docusaurus && npm install && npm start launches the documentation locally (the presence of docusaurus/package.json and docusaurus/package-lock.json confirms the npm dependency). Real‑World Use A quantitative team can clone the repo, add new strategy files to examples/batchone/, and run the backtest suite to generate fresh metrics.json reports.
