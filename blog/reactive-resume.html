Forked from amruthpillai/reactive-resume

The Problem

Creating and maintaining a resume typically means fighting with word processors, inconsistent formatting across devices, and template lock-in. Most resume builders are either closed-source SaaS products that hold your data hostage or require an account before you can do anything useful. Users end up with resumes they can't fully customize, export cleanly, or move between platforms.

What This Does

Reactive Resume is a full-stack, self-hostable resume builder. The apps/web directory contains a React client with a real-time preview editor, drag-and-drop section ordering, and a template gallery. The apps/server directory holds a Node.js backend exposing HTTP endpoints for authentication (apps/server/src/http/auth.ts), PDF generation (apps/server/src/http/resume-pdf.ts), and static asset serving (apps/server/src/static/web.ts). It also includes an MCP server (apps/server/src/mcp/server.ts) for AI integration and an OpenAPI spec generator (apps/server/src/openapi/generator.ts).

The project supports PDF, JSON, and DOCX export, import from JSON Resume format, passkey/2FA authentication, and 50+ locale files under apps/web/locales/. Docker deployment is first-class, with Dockerfile and Dockerfile.dev at the root. The README states no account is required for basic use, and self-hosting gives full data ownership.

How To Use It

Setup: The repo has apps/server/package.json and apps/web/package.json, implying a pnpm/npm workspace. Clone the repo, run pnpm install at the root, then pnpm dev to start both apps. A Dockerfile is present, so docker build -t reactive-resume . is the container path.

Configuration: Copy .env.example to .env at the root. The server needs database credentials and JWT secrets; the web app needs the server URL. AI features require API keys for OpenAI, Google Gemini, or Anthropic Claude, configured in the same .env file.

Running it: The server entry point is apps/server/src/index.ts; the web client loads from apps/web/index.html. For production, use the Dockerfile or run pnpm build in each app directory. The README documents the hosted instance at rxresu.me and docs at docs.rxresu.me.

git clone https://github.com/amruthpillai/reactive-resume.git cd reactive-resume cp .env.example .env pnpm install pnpm dev

Real-World Use

A consultancy or an individual developer who wants full control over their resume data can self-host this behind their own domain. The MCP server integration (apps/server/src/mcp/server.ts) allows AI assistants to interact with resume data programmatically, which is useful for automating resume updates from structured data sources. The OpenAPI generator (apps/server/src/openapi/generator.ts) produces a machine-readable API spec, enabling custom client integrations.

Code Health & Issues Low - No lockfile in the repo (apps/server/package.json and apps/web/package.json exist, but no pnpm-lock.yaml or package-lock.json is present). Builds are not reproducible across environments. Low - 15 test files exist, but they're concentrated on server-side HTTP handlers and utilities. The web client has no visible test coverage, which is a gap for a UI-heavy application. Low - The .superpowers/ directory contains an internal planning document, which is likely not intended for public consumption. It should be removed or gitignored.

The repo has solid CI/CD with GitHub Actions workflows for Docker builds, E2E tests, and Crowdin sync. The presence of SECURITY.md and a bug/feature request template suggests mature project governance. The MIT license is explicitly stated in the README.

The Bottom Line

Reactive Resume is a mature, well-architected open-source project with a strong feature set and real deployment options. It's best suited for developers who want a self-hosted resume service with AI capabilities, or for users who value data ownership over convenience. The missing lockfile is a minor reproducibility concern, and the lack of web client tests is worth noting, but neither blocks practical use. For a free, privacy-first resume builder, this is a credible choice.
