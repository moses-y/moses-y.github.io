kumo

Cloudflare's component library for building modern web applications.

Forked from cloudflare/kumo

The Problem

Building accessible, design-system-compliant React UIs requires deep expertise in keyboard navigation, focus management, and ARIA attributes. Most teams either ship inaccessible UIs or burn significant time reimplementing these patterns component by component. Kumo solves this by providing pre-built, accessible components that conform to Cloudflare's design system.

What This Does

Kumo is a React component library built on Base UI primitives. It exposes 50+ components including Button, Dialog, Table, DatePicker, Combobox, and charting components like BubbleMap and SankeyChart. Each component handles accessibility concerns out of the box. The library ships with a CLI (npx @cloudflare/kumo doc Button) for querying component documentation from the terminal.

The packages/kumo-docs-astro/ directory contains the documentation site built with Astro, including interactive demos for every component (see src/components/demos/). The ci/ directory contains a release pipeline with visual regression testing (ci/visual-regression/), automated changelog generation, and deployment scripts for staging and production docs sites. Lint rules in lint/ enforce design-system standards like no primitive color usage and no cross-package imports.

Real-World Use

A team building a Cloudflare dashboard can import { Button, Input, Dialog, Table } from @cloudflare/kumo and get production-ready, accessible components that match Cloudflare's visual language. Granular imports (@cloudflare/kumo/components/button) enable tree-shaking for bundle size control. Base UI primitives are re-exported for advanced customization when the pre-built components don't suffice.

Code Health & Issues

Severity: Low - Only 3 test files found across the entire repo (astro-markdown-pages.test.ts, html-to-markdown.test.ts), which is insufficient for a component library of this size. No component-level tests (unit or integration) are visible. Severity: Medium - The packages/kumo-docs-astro/ package contains 138 files (69% of the repo), suggesting the component source code itself may be minimal or embedded within the docs site rather than in a separate, cleanly isolated package. Severity: Low - No .env.example or credential handling guide for the Figma token; the README shows a commented-out cp command with a note to "set FIGMA_TOKEN" with no documented rotation or secret management pattern. Severity: Low - The ci/versioning/ scripts are shell scripts with no error handling visible from the structure alone. CI is well-configured (12 workflow files, visual regression, preview deploys) and a MIT license is present. The repo appears actively maintained.

The Bottom Line

Kumo is a production-grade component library for teams building Cloudflare-branded React applications. It eliminates the need to reimplement accessibility patterns and provides a consistent design system. The lack of component tests is concerning for a library claiming production readiness, and the codebase is heavily weighted toward the documentation site rather than the library itself. Use it if you're building within Cloudflare's ecosystem; skip it if you need a framework-agnostic or non-Cloudflare design system.
