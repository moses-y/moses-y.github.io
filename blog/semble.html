Semble: Fast Code Search for AI Agents

Semble is a local, CPU-only code search engine designed for AI coding agents. It indexes repositories and returns relevant code snippets from natural language queries, using approximately 99% fewer tokens than the common pattern of grep + full file reads.

What This Does

The core workflow is straightforward: Semble indexes a codebase (local path or git URL) in roughly 500ms, then answers natural language queries in about 1ms. It returns only the relevant code chunks, not entire files. The system uses a hybrid sparse-dense retrieval approach (BM25 + embeddings) with learned ranking, all running on CPU with no external API calls.

The entry point is src/semble/cli.py. The indexing pipeline lives in src/semble/index/, with separate modules for BM25 (bm25.py), dense embeddings (dense.py), and file walking (file_walker.py). The ranking layer in src/semble/ranking/ applies boosting and penalties to refine results.

Semble ships as both a CLI tool and an MCP server (src/semble/mcp.py). The installer (semble install) detects agents like Claude Code, Codex, and Cursor, then configures MCP integration, CLI instructions, or a dedicated sub-agent automatically.

Real-World Use

A developer using Claude Code with MCP can ask "How does this repo handle authentication?" and Semble returns the relevant code chunks directly, without the agent needing to grep for keywords and read multiple files. For CI pipelines or scripts, the CLI outputs results in JSON or markdown.

Low - The src/semble/agents/ directory contains markdown files (e.g., antigravity.md, claude.md) that appear to be agent-specific instructions, but their purpose and update cadence are undocumented.

The Bottom Line

Semble solves a real problem: reducing token waste when AI agents search codebases. The hybrid retrieval approach is sensible, the performance numbers are credible, and the zero-setup CPU-only design is practical. The lack of a lockfile and opaque benchmark results are minor concerns. This is a solid tool for teams using AI coding agents who want faster, cheaper code search without sacrificing relevance.
