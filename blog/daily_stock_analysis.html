daily stock analysis

LLM 驱动的多市场股票智能分析系统：多源行情、实时新闻、决策看板与自动推送，支持零成本定时运行。 LLM-powered multi-market stock analysis system with multi-source market data, real-time news, decision dashboard, automated notifications, and cost-free scheduled runs.

Forked from ZhuLinsen/daily_stock_analysis

The Problem

Retail investors tracking multiple markets (A-shares, HK, US, Japan, Korea) face fragmented data sources, manual analysis workflows, and no practical way to get AI-generated daily briefings without paying for expensive terminals or writing custom scripts from scratch.

What This Does

This is a full-stack LLM-powered stock analysis system. The Python FastAPI backend (api/app.py) aggregates market data from providers like AkShare, Tushare, and YFinance, then feeds it to configurable AI models (OpenAI, Claude, Gemini, local Ollama) to generate decision reports. The React/TypeScript frontend (apps/dsa-web/src/) provides a web dashboard with report views, alert management, backtesting, and portfolio tracking. An Electron desktop client (apps/dsa-desktop/main.js) wraps the web app for local use.

The system runs on GitHub Actions for zero-cost daily scheduled analysis, or via Docker for self-hosted setups. It pushes results to WeChat Work, Feishu, Telegram, Discord, Slack, or email. The api/v1/endpoints/ directory exposes 15+ endpoint modules covering analysis, agent strategy conversations, alerts, backtesting, and system configuration.

Real-World Use

A user forks the repo, configures their stock watchlist and AI API key in environment variables, and the GitHub Action at .github/workflows/00-daily-analysis.yml runs daily at market close. The system fetches prices, news, and fundamentals, generates an LLM analysis with buy/sell signals and risk scores, then pushes a formatted decision dashboard to their Telegram channel—all without any server infrastructure.

The Bottom Line

A well-structured, production-grade stock analysis system that genuinely solves a real problem for multi-market retail investors. The dual GitHub Actions + Docker deployment model is practical, and the breadth of data source and AI model support is impressive. Best suited for technically comfortable investors who want automated AI analysis without monthly subscription fees.
