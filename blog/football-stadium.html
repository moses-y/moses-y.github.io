The Problem

The inability to visualize and experience a seat's view before purchasing tickets can lead to disappointment and frustration for fans. This project, StadiView, aims to address this pain point by providing an interactive, procedural 3D football stadium concept.

What This Does

StadiView allows users to explore a virtual stadium, select from thousands of generated seats, and preview the view from each seat. The project utilizes Three.js and GSAP to render the stadium and animate camera flights. The index.html file serves as the entry point, and the src/main.js file contains the primary logic for the application. The README.md file provides detailed instructions on how to run the project locally.

Real-World Use

A practical scenario for StadiView would be for a fan looking to purchase tickets for a football game. They could use the application to explore the stadium, select a seat, and preview the view from that seat before making a purchase. For example, they could run the command npm run dev to start the development server and access the application through the local address provided by Vite.
