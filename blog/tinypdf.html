What This Does: ctx.text(), ctx.rect(), ctx.line(), ctx.image() for drawing; ctx.link() for clickable URLs; markdown() converter; build() returns Uint8Array; buildStream() emits ReadableStream<Uint8Array> for large docs. How To Use It: Setup: npm install tinypdf (package.json present); Bun users have bun.lock for reproducible installs. Config: tsconfig.json handles TypeScript compilation.
