NadirClaw

Abstract

Open-source LLM router & AI cost optimizer. Routes simple prompts to cheap/local models, complex ones to premium — automatically. Drop-in OpenAI-compatible proxy for Claude Code, Codex, Cursor, OpenClaw. Saves 40-70% on AI API costs. Self-hosted, no middleman.

The Problem

Developers using premium LLM APIs (Claude, GPT‑4, etc.) often send trivial prompts—file listings, short formatting requests, or basic queries—that could be satisfied by far cheaper models. Those “simple” calls consume premium tokens and inflate budgets, especially in CI pipelines and coding assistants that fire many small requests per minute.

What This Does

NadirClaw sits as an OpenAI‑compatible proxy (see nadirclaw/server.py) and classifies each incoming request with the model in nadirclaw/classifier.py. Based on a configurable score threshold it routes the call to a “simple” model (e.g., Gemini‑Flash) or a “complex” model (e.g., Claude‑Sonnet) as defined in nadirclaw/settings.py.

The routing logic lives in nadirclaw/routing.py, while cost aggregation and budgeting are handled by nadirclaw/budget.py and nadirclaw/report.py. A lightweight cache (nadirclaw/cache.py) prevents duplicate calls, and nadirclaw/optimize.py can trim input tokens before dispatch. The CLI (nadirclaw/cli.py) provides a setup wizard and a serve command that launches the proxy on localhost:8856.

How To Use It

Install from PyPI (uses pyproject.toml → pip)

pip install nadirclaw

Or build the Docker image (Dockerfile + docker‑compose.yml)

docker compose build docker compose up -d Setup – Run the interactive wizard to create a concrete configuration (.env derived from .env.example) and populate nadirclaw/settings.py with API keys and model choices.

nadirclaw setup Configuration – Edit the generated .env (or provide env vars directly) to set: OPENAIAPIKEY, ANTHROPICAPIKEY, etc. (keys referenced in nadirclaw/credentials.py) SIMPLEMODEL, COMPLEXMODEL, SCORETHRESHOLD (defaults are in nadirclaw/settings.py) Run the proxy – Start the server with optional verbose logging.

nadirclaw serve --verbose

The process listens on http://localhost:8856. Point any OpenAI‑compatible client (Claude Code, Cursor, Aider, etc.) to this address and it will automatically route requests. Dashboard & Reporting – Access nadirclaw/webdashboard.py via the same host/port (served under /dashboard) to view real‑time cost breakdowns, budget alerts (nadirclaw/budget.py), and saved reports (nadirclaw/report.py).

Real‑World Use

A CI job that lints code and runs unit tests can point its openai client to http://localhost:8856. Simple prompts like “list changed files” are routed to gemini-flash, while a failing test that triggers a “debug this snippet” request is sent to claude-sonnet. The CI log shows a per‑step cost column, and the nightly budget report (nadirclaw/report.py) emails the team if the configured limit is exceeded.

import openai

client = openai.OpenAI(base_url="http://localhost:8856/v1") response = client.chat.completions.create( model="gpt-4o-mini", # placeholder; actual model chosen by router messages=[{"role": "user", "content": "List changed files"}], ) print(response.choices[0].message.content)

Code Health & Issues

Low – Missing lockfile – pyproject.toml declares dependencies but no poetry.lock/requirements.txt; reproducible builds rely on exact version pins. Low – Limited type coverage – Several modules (e.g., nadirclaw/optimize.py, nadirclaw/routing.py) lack type hints, reducing static analysis confidence. Medium – Secret handling – API keys are loaded from environment variables (nadirclaw/credentials.py) but the repo does not enforce .env exclusion beyond .gitignore; accidental commit risk exists. Low – Test completeness – 30 test files cover core functionality, and CI (.github/workflows/ci.yml) runs them on each push, indicating decent test hygiene. Low – Documentation – README, docs folder, and inline comments explain setup and routing; however, no generated API reference for internal modules. Low – License present – LICENSE file included, satisfying legal requirements.

Overall the codebase follows a clear modular layout, and the CI pipeline validates each commit.

The Bottom Line

NadirClaw delivers a practical, self‑hosted proxy that can cut LLM spend by routing trivial prompts to inexpensive models while preserving existing OpenAI‑compatible workflows. It’s ready for production use provided you add a dependency lockfile and enforce secret‑git hygiene. Ideal for teams with high‑frequency coding assistance or CI pipelines that want immediate cost control without redesigning their client code.
