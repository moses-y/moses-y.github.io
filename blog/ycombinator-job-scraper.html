The Problem: Tech professionals spend significant time manually monitoring Y Combinator's job board for relevant listings. This repo automates that fetch and routes new openings via WhatsApp, targeting a specific timing constraint (10 am East African Time) and eliminating daily manual checks.

What This Does: The core logic lives in src/scraper.py, which extracts job listings from Y Combinator's board. src/database.py persists seen entries to avoid duplicates, and src/messaging.py integrates with Twilio to send WhatsApp alerts. An entry point at src/main.py orchestrates the pipeline, scheduled via the GitHub Actions workflow defined in .github/workflows/scraper.yml. Dependensions are listed in requirements.txt, but no lockfile is present, meaning installs may not be fully reproducible across environments.

How To Use It: Setup: Run pip install -r requirements.txt to install listed dependencies. Configuration requires four environment variables: TWILIOACCOUNTSID, TWILIOAUTHTOKEN, TWILIOPHONENUMBER, and YOURPHONENUMBER, as documented in the README. Running: Execute python src/main.py to start the scraper. The GitHub Actions workflow can be used to automate scheduling. Real-World Use: In practice, a developer running this scraper each morning receives a curated WhatsApp message with new Y Combinator listings, skipping manual board checks. The src/scraper.py function parses the board, src/database.py tracks previously seen IDs, and src/messaging.py formats and sends only novel entries via Twilio. If a new listing appears that wasn't in the database, it triggers immediately. Code Health & Issues: Low risk: No lockfile (requirements.txt only) leads to non-reproducible builds; pip freeze should be committed for consistency. Med risk: Environment variables for Twilio credentials are documented but not enforced or masked; committing .env or exposing keys in workflow logs could be a vector. High risk: Scraper depends on Y Combinator's HTML structure without apparent anti-bot mitigation (headless Chrome/chromedriver in assets/), which may break with site changes or trigger rate limits. Positive: Four test files exist (tests/testscraper.py, etc.), and GitHub Actions CI is configured in .github/workflows/scraper.yml, providing basic regression protection.

The Bottom Line: This is a functional, lightweight automation for individual job seekers who want daily Y Combinator alerts without manual checks. It's well-structured with clear module separation and test coverage, but the missing lockfile, unsecured credential handling, and fragile scraping surface make it best suited for personal use or a controlled CI environment rather than production-grade hiring pipelines.
