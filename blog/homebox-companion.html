Now What This Does: 2-3 paragraphs.

Paragraph 1: It's a full-stack app with Svelte frontend and Python Flask backend. The frontend (130 files in frontend/) handles camera capture, AI interaction, and inventory editing. The server (26 files in server/) provides REST APIs for authentication, item management, and AI vision processing via OpenAI GPT-5 models.

Paragraph 2: The workflow flows through capture, AI detection, review, and submission. Frontend workflow files like frontend/src/lib/workflows/capture.svelte.ts orchestrate camera access, while server/api/vision.py and server/api/items.py handle the backend AI analysis and inventory persistence. A correction panel (AiCorrectionPanel.svelte) allows users to refine AI suggestions before commit.

Paragraph 3: It integrates with Homebox's existing location and tag infrastructure, supporting QR code scanning for location selection and custom field editing through the form components under frontend/src/lib/components/form/.

Now How To Use It:

Setup: The repository uses npm for the frontend (frontend/package.json) and Python dependencies managed via pyproject.toml. Docker is the primary deployment model - docker-compose.yml defines the service, and the Dockerfile builds the container. Alternatively, the demo can be run with docker run -p 8000:8000 -e HBCLLMAPIKEY=sk-your-key -e HBCHOMEBOXURL=https://demo.homebox.software ghcr.io/duelion/homebox-companion:latest.

Configuration: Two environment variables are required: HBCLLMAPIKEY (your OpenAI API key) and HBCHOMEBOXURL (the Homebox instance URL). These are configured in .env.example at the repository root and passed via the Docker compose environment section or docker run -e flags.

Running it: Start the stack with docker compose up -d after placing your key in the compose file or exporting it as an env var. The server starts on port 8000 (mapped from the container). Open http://localhost:8000 in a browser, login with your Homebox credentials, and follow the guided workflow.

Now Real-World Use:

Scenario: A hobbyist inventories a home workshop. They open the app, select their Homebox location (or scan a QR code), position items under the camera, and capture photos. The AI (using GPT-5 mini via LiteLLM) returns identified items with quantities and metadata. The user reviews the suggestions in the review workflow, correcting any misidentifications via the AiCorrectionPanel.svelte, then submits the batch. Items appear instantly in the Homebox inventory with attached photos.

Code snippet example: The AI vision call flows through server/api/vision.py which uses LiteLLM to send the captured image to OpenAI's GPT-5 model, returning structured item data that the frontend stores via frontend/src/lib/api/items.ts.
