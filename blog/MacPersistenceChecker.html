MacPersistenceChecker

macOS persistence mechanism scanner with code signature verification and timeline tracking.

Forked from Pinperepette/MacPersistenceChecker

The Problem

macOS leaves persistence mechanisms scattered across LaunchAgents, cron jobs, kernel extensions, login items, and 20+ other locations. Users and analysts have no unified view of what runs automatically, why it runs, or whether it's legitimate. Malware and unwanted software exploit this opacity. Existing tools like Autoruns are Windows-centric and don't understand macOS-specific mechanisms.

What This Does

MacPersistenceChecker is a native macOS app (Swift, 112 files) that scans 22+ persistence mechanisms, verifies code signatures, and presents findings through a knowledge graph rather than a flat list. The scanner layer in Services/Scanners/ contains individual scanners for each mechanism—LaunchAgentScanner.swift, CronJobScanner.swift, KextScanner.swift, DylibHijackingScanner.swift, and others—all coordinated by PersistenceScanner.swift.

The app adds context through multiple analysis layers. Services/Trust/CodeSignatureVerifier.swift and TrustVerifier.swift check signatures. Services/Analysis/ contains behavioral analyzers: LOLBinsDetector.swift, IntentMismatchAnalyzer.swift, SignedButDangerousAnalyzer.swift, and InvasivenessScorer.swift. Risk scoring lives in Services/Risk/RiskScorer.swift. The AI layer (Services/AI/) is optional and uses Anthropic's Claude API for triage, clustering, and natural-language threat hunting. Core scanning and scoring run locally.

The app also includes a monitoring mode (Services/Monitor/) that watches for persistence changes over time, snapshot diffing (Models/SnapshotDiff.swift), and containment actions (Services/Containment/). MITRE ATT&CK mappings are in Models/MITREMapping.swift.

How To Use It

Build from source with Swift Package Manager, or download the release DMG from the GitHub releases page. The app targets macOS 13+, universal binary.

Build from source swift build -c release Or use the provided build script ./build.sh

Configuration is minimal. The app requires Full Disk Access to scan system locations; Services/Permissions/FullDiskAccessChecker.swift handles detection and the onboarding view walks users through granting it. AI features require an Anthropic API key entered in Settings → AI, stored in the macOS Keychain. The monitoring feature needs to be enabled in Settings → Monitoring.

Run the app directly after build. The main entry point is MacPersistenceCheckerApp.swift. First scan takes under 30 seconds per the README.

Real-World Use

A user suspects malware after installing a cracked application. They run MacPersistenceChecker, which scans all persistence locations and produces ~6,800 items. The knowledge graph clusters these into ~280 concepts. The user reviews the SignedButDangerousAnalyzer output, which flags signed binaries performing suspicious actions. The BTMDatabaseScanner reveals a new launch agent tied to the install. The user applies containment via SafeContainmentService.swift, which blocks the network path and disables the agent. A snapshot diff before/after removal confirms the item is gone.

The Bottom Line

MacPersistenceChecker is a serious, well-architected macOS security tool that fills a real gap: comprehensive persistence visibility with context-aware analysis. The knowledge graph approach and MITRE mapping are thoughtful. The lack of tests and CI is the main concern for a security tool, and the AI features, while useful, are not the core value—the local scanning and scoring are. Suitable for security-conscious macOS users and incident responders who want a free, open-source alternative to commercial endpoint tools.
