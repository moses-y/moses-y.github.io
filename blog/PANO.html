PANO

🔍 PANO: Advanced OSINT investigation platform combining graph visualization, timeline analysis, and AI assistance to uncover hidden connections in data. Built with Python and modern Qt.

Forked from ALW1EZ/PANO

The Problem

Investigators handling digital evidence—from open-source intelligence (OSINT) to corporate fraud cases—often juggle multiple tools for graph analysis, timeline mapping, geolocation, and entity extraction. Manually stitching these together wastes time and risks missing cross‑domain connections. PANO aims to unify these workflows into one desktop application.

What This Does

PANO is a Python/PySide6 desktop application that combines interactive graph visualization, timeline analysis, map integration, and AI‑assisted entity extraction. The core entity model lives in entities/ (person, email, location, etc.), while transforms/ implements automated lookups (e.g., emaillookup.py uses GHunt for Google account data, reverseimagesearch.py for image analysis). The ui/ folder contains the Qt front‑end: graph view, timeline, map components, and an AI dock (components/aidock.py) that provides natural‑language queries to a local or remote LLM. The helpers/ module includes cross‑examination (crossexamination.py) and media analysis (mediaanalyzer.py). The start_pano.sh/.bat scripts handle environment setup and dependency installation.

Real‑World Use

An investigator adds an email address as an entity, runs the email lookup transform, and PANO automatically creates linked entities (Google account, calendar events, location history). Those events appear on the timeline, and geographic coordinates are plotted on the map. The investigator can then run a username search transform to find social media profiles, and the graph updates in real time. Example workflow:

The Bottom Line

PANO is a well‑structured OSINT investigation platform with a broad feature set—graph, timeline, map, and AI integration—all in a single desktop app. However, the lack of tests, CI, and a reproducible build makes it risky for production or team use. Suitable for individual researchers or small teams who can tolerate manual validation and are comfortable with the non‑commercial license.
