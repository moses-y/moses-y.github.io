The Problem

Teams building React applications often need polished micro‑interactions (spinners, hover effects, card layouts) without spending time on animation primitives or wiring motion libraries. This repo supplies a ready‑made catalog of motion‑driven UI pieces and a CLI that injects them into a project.

What This Does

The repository is split into three main folders: registry/ – contains ~175 JSON configuration files (registry/ui/.json, registry/hooks/.json, registry/lib/*.json) that define transition presets, hook options, and preset springs. Corresponding TypeScript definitions live beside them (e.g., registry/hooks/use-mouse-position.ts, registry/ui/hover/glow-button.tsx). api/ – a single TypeScript file api/checkout-status.ts exposing a status‑check endpoint. (root)/ – entry‑point index.html, build configs (package.json, package-lock.json), and CI workflow .github/workflows/ci.yml.

The registry/ui directory holds over 120 animation definitions (spinners, entrance fades, cursor trails, magnetic buttons, etc.) and the TSX implementations for a subset of them. Hooks such as use-scroll-progress, use-mouse-position, and use-reduced-motion are exported from registry/hooks/. Preset spring configurations live in registry/lib/presets.ts.

How To Use It

Setup

The project uses npm (see package.json). Install the package:

npm install @subhanhq/amicro or pnpm add @subhanhq/amicro

Configuration

The README provides an .env.example file (present in the root) that documents any required environment variables; currently no vars are mandatory, but keep the file handy if future additions require keys.

Running the CLI

After installation, the bundled CLI can be invoked:

npx @subhanhq/amicro@latest init # creates amicro config in your React project npx @subhanhq/amicro@latest add fade-in # copies the fade‑in component into your codebase

Alternatively, the shadcn CLI can pull components directly from the remote registry:

npx shadcn add @amicro/fade-in # via namespaced registry mapping or npx shadcn add https://raw.githubusercontent.com/Subhan-code/Amicro--Micro-transitions-/main/registry/ui/fade-in.json

Adding a component

Running npx @subhanhq/amicro@latest add card-arc-5 will drop the relevant TSX/JSON files into your components/amicro folder and update components.json with the @amicro registry entry.

Real‑World Use

Imagine a dashboard that needs a subtle “glow‑on‑hover” effect on action buttons. Instead of writing keyframes, import the pre‑defined hook and component:

import { useMousePosition } from '@amicro/use-mouse-position'; import GlowButton from '@amicro/glow-button';

export const ActionBar = () => { const { x, y } = useMousePosition(); return <GlowButton data-pointer="{x}, {y}">Save</GlowButton>; };

The use-mouse-position hook lives in registry/hooks/use-mouse-position.ts and the button variant is defined by registry/ui/hover/glow-button.json with its TSX implementation at registry/ui/hover/glow-button.tsx.

Code Health & Issues

No test files detected – repository‑wide untested code paths. CI configured – .github/workflows/ci.yml exists, but without tests the pipeline likely only lints/builds. Large surface of JSON configs – 175 files define animations; only a subset has accompanying TSX implementations, which may lead to unused definitions if not explicitly imported. Single API file – api/checkout-status.ts is the only source code beyond the UI catalog; no broader business logic is present. License and contributing docs present – LICENSE, CODEOFCONDUCT.md, and CONTRIBUTING.md are included, indicating an open‑source-friendly project.

The Bottom Line

This repo is a focused library of React micro‑interactions and a convenient CLI for scaffolding them into new or existing projects. It shines for teams that need ready‑made motion primitives without building animation pipelines from scratch. The main trade‑off is the absence of test coverage and a relatively thin functional surface beyond the UI catalog; it is best suited as a supplemental design‑system addition rather than a full‑featured application foundation.
