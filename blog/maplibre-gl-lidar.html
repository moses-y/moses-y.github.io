The Problem: One paragraph about the specific pain point this solves. LiDAR visualization in web GIS is typically heavy, requires server-side preprocessing, or lacks easy-to-use browser-based streaming viewers. This repo provides a client-side solution with COPC/EPT streaming and deck.gl integration, targeting developers who need to display large point clouds in MapLibre maps without building custom streaming pipelines.

What This Does: 2-3 short paragraphs. Reference actual files/folders. It implements a LidarControl class in src/lib/core/LidarControl.ts that manages point cloud loading, viewport-based COPC streaming via CopcStreamingLoader.ts and EptStreamingLoader.ts, and rendering through src/lib/layers/PointCloudManager.ts using deck.gl's PointCloudLayer. GUI controls live in src/lib/gui/ - ClassificationLegend.ts toggles classification types, DualRangeSlider.ts and RangeSlider.ts handle point size and elevation filtering, built into a panel via PanelBuilder.ts. Hooks useLidarState.ts and usePointCloud.ts in src/lib/hooks/ provide React state management, while the vanilla API exposes loadPointCloud() for programmatic control. WASM-accelerated LAZ decompression runs through public/lazrswasmbg.wasm and src/lib/loaders/laz-rs-wasm/lazrs_wasm.js, enabling efficient LAZ/LAZ parsing in the browser.
