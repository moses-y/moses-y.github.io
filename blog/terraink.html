## The Problem TerraInk addresses the pain point of generating high-quality, customizable city map posters from real OpenStreetMap data without manual cartography. The application processes geocoded locations through MapLibre rendering, applies user-selected themes and typography, and exports print-ready PNGs at defined dimensions. It targets designers, developers, and map enthusiasts who need automated poster generation rather than static, manually designed maps.

## What This Does TerraInk is a React + TypeScript application (75 TypeScript, 42 TSX files) that orchestrates map generation through a feature-separated architecture. Core data flow runs through src/core/http/index.ts for geocoding and tile fetching, src/features/map/infrastructure/maplibreStyle.ts for MapLibre styling, and src/features/poster/infrastructure/renderer/ for canvas-based export. The theme system lives in src/features/theme/, with src/data/themes.json and src/data/layouts.json providing default configurations. Geocoding is handled by src/features/location/infrastructure/nominatimAdapter.ts and src/features/location/infrastructure/geolocation.ts, while marker rendering and custom icon storage are in src/features/markers/. Exports are generated via src/features/export/infrastructure/pngExporter.ts, layeredSvgExporter.ts, and pdfExporter.ts, with UI controls in src/features/poster/ui/. The application is containerized via Dockerfile and docker-compose.yml, with environment configuration outlined in .env.example.

## How To Use It Setup requires installing dependencies and running the development server. From the repository structure:

bash bun install bun run dev # or with npm/pnpm npm install npm run dev The Vite development server is configured in vite.config.js. For production or containerized deployment, Dockerfile and docker-compose.yml define the build and run pipeline. Environment variables are declared in .env.example; copy this file and adjust as needed for MapLibre or API keys. To start the containerized version:

bash docker compose up --build The application launches at http://localhost:5173 (Vite default) or the port configured in vite.config.js.

## Real-World Use A graphic designer needs a limited-edition city map poster for a coffee shop opening. They open TerraInk, search “Portland, OR” via the geocoding UI (src/features/location/ui/LocationSection.tsx), select a dark-matter theme from the theme picker (src/features/theme/ui/ThemeCard.tsx), adjust typography and layer visibility, then export a 24x36in PNG at 300 DPI via src/features/export/infrastructure/pngExporter.ts. The file is ready for print-on-demand workflows without needing QGIS or manual design.
