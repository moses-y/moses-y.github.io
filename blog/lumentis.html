The Problem

Meeting transcripts and large unstructured docs are time‑consuming to summarise; engineers must manually outline, write, and format reports. Lumentis automates this with a single command, pulling in LLM calls to generate polished docs.

What This Does

Lumentis reads a transcript or notes, prompts the user for themes and audience, then runs a wizard (runWizard in src/app.ts) that orchestrates LLM calls, outline generation, and page creation. The core LLM logic lives in src/ai.ts (functions such as callLLM, callOpenAI, callAnthropic), while type definitions are in src/types.ts (AICallerOptions, OpenAIContent, etc.). UI‑related prompts are defined in src/prompts.ts, and utility functions such as parsePlatformIndependentPath reside in src/utils.ts. The generated output is written to a Nextra‑compatible docs folder via src/page-generator.ts.

How It Is Wired

How To Use It

# from the root of a fresh directory
npx lumentis

The CLI prompts for a transcript/doc, then asks about theme, audience, and outline preferences. API keys for the chosen LLM providers (OpenAI, Anthropic, Gemini) must be available; the code references them but no .env file is committed. If you have previously run Lumentis via npx, clear the cache with npx clear-npx-cache or pin a version (npx lumentis@0.2.1-dev).

Real-World Use

A product team uploads a recorded meeting transcript. Lumentis generates an outline, lets the reviewer select sections, and produces a Vercel‑deployable docs site in under a minute, costing a few cents depending on model choice. The team can swap models per stage (e.g., Sonnet for outline, Haiku for body) as documented in the README examples.

The Bottom Line

The repo delivers a functional one‑click doc generator with clear LLM orchestration, but the codebase lacks a lockfile, CI, and automated dependency updates, and the main entry point is a large file that spreads risk. It works well for quick, low‑cost documentation sprints, yet teams needing reproducible builds and ongoing maintenance will want to add the missing scaffolding.
