The Problem

Content creators often spend hours manually sifting through long videos to find highlights. The process requires downloading, transcribing, analyzing, and cutting video segments—tasks that are repetitive and error‑prone. A unified system that automates download, AI‑based highlight detection, and clip generation would save time and reduce manual effort.

What This Does

AutoClip automates the entire highlight‑generation workflow.

  • The FastAPI backend (backend/main.py) exposes REST endpoints (see backend/api/v1/*.py) for downloading videos from YouTube and B站, triggering AI analysis, and retrieving processed clips.
  • The processing pipeline is split into five stages (backend/pipeline/step1_outline.py → step5_clustering.py), each wrapped by backend/services/processing_service.py and orchestrated by backend/services/processing_orchestrator.py.
  • Asynchronous jobs are dispatched through Celery (backend/cli.py, backend/desktop_main.py), with progress pushed via WebSocket (backend/api/v1/websocket.py).
  • The React frontend (frontend/src/App.tsx) consumes these APIs, shows real‑time progress, and lets users arrange or edit generated clips.

Execution starts at backend/main.py. A GET to /api/v1/processing/ triggers process_video(), which hands the job to Celery. The worker calls processing_service.process(), which delegates to processing_orchestrator.run_pipeline(). Each step writes temporary files to backend/core/unified_storage.py, updates the SQLite database via the repositories, and emits progress through the WebSocket. The React app displays progress, then lists the generated clips for user interaction.

The module graph has a single hub in backend/app_factory.py; changing any router requires updating this file. No circular imports exist, but the orchestrator’s tight coupling to the step modules means altering a step requires updating the orchestrator.

How To Use It

# 1. Clone
git clone https://github.com/moses-y/autoclip
cd autoclip

# 2. Build Docker images (recommended)
docker build -t autoclip:latest -f Dockerfile .

# 3. Start services
docker-compose up -d  # spins up FastAPI, Redis, Celery

# 4. Verify backend
curl http://localhost:8000/docs  # OpenAPI UI

# 5. Run frontend
cd frontend && npm ci && npm run dev

Configuration

  • Environment variables are read from backend/.env (see backend/core/config.py).
  • Redis URL, database path, and AI provider keys must be set.
  • The default AI provider is 通义千问; swap to another by editing backend/core/llm_manager.py.

Running the CLI

# Trigger a manual pipeline via CLI
python backend/cli.py process https://www.youtube.com/watch?v=XXXX

Real-World Use

A marketing team uploads a 2‑hour interview. They hit “Generate Highlights” on the web UI. The backend downloads the video, runs the AI pipeline (outline → timeline → scoring → title → clustering → video), and streams progress to the client. Once done, the UI presents a drag‑and‑drop list of 8‑second clips for quick social‑media publishing.

The Bottom Line

AutoClip delivers a complete, Docker‑ready pipeline for AI‑driven video highlight extraction. Its modular design—FastAPI + Celery + React—makes it easy to extend or replace individual components. The tight coupling in the orchestrator is the main architectural cost but does not impede day‑to‑day usage. The project is suitable for teams that need rapid video content creation without building the infrastructure from scratch.

Pin third-party GitHub Actions to a commit SHAhigh3 occurrences

dtolnay/rust-toolchain@stable, Swatinem/rust-cache@v2, softprops/action-gh-release@v2
A tag can be moved, so the action running with your token and secrets is whatever its owner last pushed; this is how tj-actions/changed-files leaked secrets from thousands of repos.
Fix: Replace each @vN with the 40-character commit SHA, keep # vN as a comment, and let Dependabot bump the SHAs.

A failing test suite reports a green check, which is precisely the path this audit exists to close.
