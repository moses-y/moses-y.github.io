The Problem

Obsidian users often struggle to build functional, visually polished dashboards from scratch. The default note-taking experience offers little in the way of customizable home pages, and assembling widgets, styling, and data views requires significant CSS and Dataview expertise. This repo addresses that by packaging complete, ready-to-copy dashboard templates.

What This Does

Obsidian-Dashboard-Gallery is a collection of four distinct Obsidian dashboard themes. Each theme is a pair of files: a Markdown dashboard in dashboards/ (e.g., Dashboard-Zen.md) and its companion stylesheet in .obsidian/snippets/ (e.g., Dashboard-Zen.css). The dashboards leverage the Dataview plugin to pull in vault data, and some include widgets like weather and clocks that require an OpenWeatherMap API key.

The repo is purely content — there is no application code, build system, or runtime. It's a gallery of templates, documented in a multilingual README.md (with Spanish, Portuguese, and Chinese translations in docs/). The .github/ folder contains issue templates for bug reports and dashboard requests, signaling an intent to grow the collection.

How To Use It

There is no installation or build step.

Setup: Clone the repository. Copy the .md file for your chosen dashboard (e.g., dashboards/Dashboard-Brutalist.md) and its corresponding .css file (.obsidian/snippets/Dashboard-Brutalist.css) into your Obsidian vault.

Configuration: Enable the Dataview community plugin (with JavaScript enabled). For the Brutalist and Komorebi themes, obtain a free API key from OpenWeatherMap and add it where the dashboard's code expects it (the README points to the API as a requirement).

Running it: Open the copied .md file in Obsidian. No commands or scripts are involved.

git clone https://github.com/InlitX/Obsidian-Dashboard-Gallery.git Then manually copy the desired .md and .css files into your vault.

Real-World Use

A user with a cluttered vault can adopt the Zen dashboard to create a personal command center. After copying the files, they'd enable Dataview, then customize the dashboard's Markdown to reference their own folders (e.g., changing a task query to target their Inbox/ folder). The result is a clean, glassmorphic home page with habit tracking and a task pipeline, without writing any CSS.

Code Health & Issues

The repo is straightforward, but a few points stand out: Med - No test files - There is no test suite, but the content is static Markdown and CSS; automated testing is unconventional here. Med - No CI/CD - No automated checks for link validity, CSS syntax, or Markdown formatting. A simple linting workflow would prevent broken previews. Low - External API dependency - The weather widgets require an OpenWeatherMap key. If that service changes its API, the dashboards break without a clear update path. Low - No versioning or changelog - Users copying files get a snapshot; there's no mechanism to track updates to the templates.

The repository is otherwise clean: MIT licensed, has contribution guidelines, and a code of conduct.

The Bottom Line

A practical, well-presented resource for Obsidian users who want polished dashboards without the CSS effort. It's not software in the traditional sense, so the lack of tests and CI is unsurprising. Best suited for individual knowledge workers or teams standardizing their Obsidian setup, provided they accept the manual copy-and-maintain workflow.
