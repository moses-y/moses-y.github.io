The Problem

Applications that need financial market data—prices, dividends, splits, fundamentals, live quotes—typically face a choice between expensive vendor APIs or scraping HTML pages. yfinance solves this by wrapping Yahoo Finance's public JSON endpoints in a clean Python API, giving developers programmatic access to a broad range of market data without API keys or paid subscriptions.

What This Does

yfinance is a Python library that downloads and normalizes market data from Yahoo Finance. The core entry point is yfinance/init.py, which exposes the main components: Ticker and Tickers for single and multi-ticker queries, download() for bulk historical data, Market for market-level info, Search for quotes and news, and Screener for building filtered market queries. Live streaming is handled by yfinance/live.py via WebSocket and AsyncWebSocket classes.

The library handles data repair and validation internally—yfinance/data.py and yfinance/base.py contain the core fetching and normalization logic, while yfinance/pricerepair.py (referenced in the docs) fixes common errors like bad dividends and stock splits. The tests/ directory contains 100+ files with fixture data covering edge cases across global exchanges, suggesting significant maturity in handling real-world data quirks.

How To Use It

Setup: Install from PyPI. The repo uses setup.py for packaging and requirements.txt for dependencies. No lockfile is present, so builds are not fully reproducible.

pip install yfinance

Configuration: No API keys or environment variables required. Optional configuration for caching and logging is documented in doc/source/advanced/config.rst and doc/source/advanced/caching.rst.

Running it: Import the library in Python and call the high-level functions. The README documents the primary interface:

import yfinance as yf

Download historical data for a ticker

data = yf.download("AAPL", period="1mo") print(data.head())

Get a Ticker object for detailed info

ticker = yf.Ticker("MSFT") print(ticker.info["marketCap"])

Real-World Use

A portfolio tracking service could use yfinance to pull daily closing prices for a watchlist, compute returns, and detect corporate actions. The library's Tickers class handles multiple symbols efficiently, and the repair logic in yfinance/data.py helps ensure dividend and split adjustments are applied correctly—critical for accurate backtesting.

import yfinance as yf import pandas as pd

symbols = ["AAPL", "MSFT", "GOOGL"] data = yf.download(symbols, period="6mo", groupby="ticker") returns = data["Close"].pct_change().dropna()

Code Health & Issues

Low - No lockfile for dependencies - requirements.txt pins versions at a coarse level, so builds may differ across environments. This is common for libraries but worth noting for reproducibility. Low - Legacy CI configuration - .travis.yml is present but the active CI appears to be GitHub Actions (.github/workflows/ contains pytest.yml.disabled, ruff.yml, pyright.yml). The disabled pytest workflow is a minor concern—test CI may not be running in this fork. Low - Unsupported Python version badge - README claims Python 2.7 support, which is almost certainly stale given the modern codebase and dependencies. Clean aspects - The test suite is extensive with fixture data covering real-world edge cases across multiple exchanges. Type checking (pyrightconfig.json) and linting (ruff.yml) are configured. The codebase has clear module separation (domain/, data.py, live.py, lookup.py).

The Bottom Line

yfinance is a mature, well-tested library that solves a real problem—free, programmatic access to financial market data. It is battle-tested in production (25k+ stars upstream) and has solid documentation and test coverage. The main risks are Yahoo's terms of service and the possibility of API changes breaking the library. It is well-suited for research, prototyping, and internal tools where free data outweighs the legal and reliability trade-offs.
