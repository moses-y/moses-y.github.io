The pipeline

How a repository gets read

Seven stages turn a repository I have never opened into something I can argue about - what it is built from, what it commits to, and where those commitments are already costing it. 55 scripts, no model in the scoring path, 188 assertions across 11 suites holding the claims in place. Every stage writes a file the next one reads, so any number on this site can be walked back to the check that produced it.

  1. Census

    Enumerates every repository and its facts - language, size, licence, lockfile, last push - into a single feed.

    forks.json

  2. Structure

    Walks the file tree and parses the sources into a module graph: imports, edges, cycles, depth.

    structure/<id>.deep.json

  3. Supply

    Resolves dependency manifests and matches them against the OSV advisory database.

    data/osv.json

  4. Hygiene

    62 checks across CI, tests, secrets, runtime and supply chain - each one a finding with a severity and a count.

    data/hygiene.json

  5. Grade

    Charges those findings to 8 weighted axes. Deterministic: the same inputs grade identically, which is the only reason it is safe to publish.

    data/grades.json

  6. Meaning

    Embeds each repository, draws semantic and dependency-derived edges, and clusters them by modularity rather than by name.

    data/relations.json

  7. Publish

    Emits a declared schema and an llms.txt traversal protocol, so an agent can answer a question here for about a kilobyte instead of parsing the whole index.

    data/schema.json

Not analysed never renders as clean. A repository graded without module-level analysis is marked partial and loses saturation on the graphs, because a neutral score on an axis nothing measured is a false claim.

Unaudited is not a grade. It gets a colour outside the scale entirely, not the bad end of it.

Every claim states its provenance. Facts are tagged extracted or inferred per fact, not per page - a dependency edge names its packages and can be checked; a similarity edge is a number from a model and says so.
